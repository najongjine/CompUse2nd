1. 컴퓨터 일반

01. 컴퓨터의 개념과 특징

컴퓨터(EDPS)는 입력된 자료(Data)를 정해진 절차에 따라 처리하여 유용한 정보(Information)로 바꾸는 장치이다.
예: 학생들의 점수(자료)를 계산하여 학급 평균(정보)을 구한다.

[컴퓨터의 주요 특징]
- 자동성: 프로그램에 따라 작업을 자동으로 처리한다.
- 정확성: 주어진 자료와 명령에 따라 정확하게 처리한다.
- 범용성: 계산, 문서 작성 등 다양한 작업에 활용한다.
- 신속성: 많은 자료를 빠르게 처리한다.
- 호환성: 다른 기기나 프로그램과 자료를 주고받거나 함께 사용할 수 있다.
- 대용량성: 많은 자료를 저장하고 처리한다.

[초기 컴퓨터의 구분]
- 에니악(ENIAC): 초기의 대표적인 전자식 컴퓨터. 프로그램 외장 방식으로, 배선과 스위치를 바꾸어 작업을 지정했다.
- 에드삭(EDSAC): 최초의 실용적인 프로그램 내장 방식 컴퓨터. 프로그램을 기억장치에 저장하여 실행했다.
- 에드박(EDVAC): 프로그램 내장 방식과 2진법을 채택한 컴퓨터. 폰 노이만과 관련된다.
- 유니박(UNIVAC): 최초의 상업용 컴퓨터.

※ 프로그램 외장 방식: 프로그램을 배선·스위치 등으로 설정한다.
※ 프로그램 내장 방식: 프로그램을 기억장치에 저장하고, 명령을 차례로 꺼내 실행한다.

[GIGO와 수동성]
GIGO(Garbage In, Garbage Out)는 잘못된 자료를 입력하면 잘못된 결과가 나온다는 뜻이다.
컴퓨터는 입력된 자료와 명령에 따라 작동하므로, 자료의 오류를 스스로 모두 판단하여 고치지는 못한다. 이를 수동성과 연결하여 기억한다.

[시험 핵심 암기]
ENIAC → 프로그램 외장 / EDSAC → 프로그램 내장 / EDVAC → 내장·2진법·폰 노이만 / UNIVAC → 상업용
GIGO → 잘못된 입력은 잘못된 출력으로 이어짐 → 수동성

02. 컴퓨터의 세대별 특징

컴퓨터의 세대는 주요 전자 소자의 발전에 따라 구분한다. 소자가 작아지고 집적도가 높아지면서 컴퓨터도 소형화·고속화되었다.

[1세대: 진공관]
- 주요 소자: 진공관. 기억장치로 자기드럼 등을 사용했다.
- 기계어를 사용했으며, 하드웨어 개발에 중점을 두었다.
- 일괄 처리: 자료를 모아 한꺼번에 처리한다. 오프라인 방식이 중심이었다.

[2세대: 트랜지스터(TR)]
- 고급언어와 운영체제(OS)를 도입했다.
- 온라인 실시간 처리: 통신으로 연결하여 자료가 들어오면 즉시 처리한다.
- 다중 프로그래밍: 여러 프로그램을 메모리에 올려 두고, 한 프로그램이 입출력을 기다리면 다른 프로그램을 실행한다.

[3세대: 집적회로(IC)]
- 시분할 처리(TSS): CPU 시간을 잘게 나누어 여러 사용자에게 번갈아 제공한다.
- 문자·표식 인식 기술 활용: OCR(광학 문자 판독), OMR(광학 마크 판독), MICR(자기 잉크 문자 판독).
- 경영정보시스템(MIS): 경영자의 의사 결정에 필요한 정보를 제공한다.

[4세대: 고밀도 집적회로(LSI)]
- 개인용 컴퓨터(PC)가 보급되고 네트워크가 발달했다.
- 분산 처리: 여러 컴퓨터가 작업을 나누어 처리한다.

[5세대: 초고밀도 집적회로(VLSI)]
- 인터넷과 인공지능(AI)이 발달했다.
- 퍼지 이론: '조금 덥다'처럼 애매한 정도를 다룬다.
- 전문가 시스템: 전문가의 지식과 추론 방법을 이용하여 문제 해결을 돕는다.

[시험 핵심 암기]
소자 순서: 진공관 → 트랜지스터(TR) → 집적회로(IC) → 고밀도 집적회로(LSI) → 초고밀도 집적회로(VLSI)
세대 연결: 1세대 기계어·일괄 처리 / 2세대 고급언어·OS·다중 프로그래밍 / 3세대 시분할·MIS / 4세대 PC·분산 처리 / 5세대 AI·전문가 시스템

03. 처리하는 자료에 따른 컴퓨터의 분류

[디지털 컴퓨터]
숫자나 문자처럼 구분되는 비연속적(이산적) 자료를 처리한다. 내부에서는 자료를 0과 1로 표현한다.
예: 인원수, 상품 수량 등을 계산하는 개인용 컴퓨터(PC).

[아날로그 컴퓨터]
온도·전류·속도처럼 연속적으로 변하는 물리량을 처리한다. 주로 과학·군사 분야의 특수 목적에 사용한다.
예: 전압의 연속적인 변화를 이용하여 물리 현상을 모의 계산한다.

[하이브리드 컴퓨터]
디지털과 아날로그 컴퓨터의 장점을 결합한 컴퓨터이다. 디지털의 정밀한 계산·논리 처리와 아날로그의 연속량 처리를 함께 활용한다.

[디지털과 아날로그의 핵심 비교]
비교 항목: 디지털 / 아날로그
- 입력: 숫자·문자로 표현한 이산적 자료 / 연속적으로 변하는 물리량
- 출력: 주로 숫자·문자 / 주로 그래프 등 연속적인 결과
- 연산: 산술·논리 연산 / 미분·적분 연산
- 구성 회로: 논리 회로 / 증폭 회로
- 프로그래밍: 명령을 작성하여 실행 / 회로 연결·설정으로 계산 수행
- 정밀도: 자릿수를 늘려 필요한 수준까지 높일 수 있음 / 회로·측정 장치의 정밀도에 제한됨
- 기억 기능: 있음 / 일반적으로 없음
- 적용 분야: 범용(개인용 등) / 특수 목적용(과학용·군사용 등)

※ 미분은 변화율을 구하는 것, 적분은 변화량을 누적하여 합하는 것이다.
※ 시험의 기본 비교에서 프로그램은 디지털은 '필요', 아날로그는 '불필요'로 구분한다.

[시험 핵심 암기]
디지털 → 비연속·이산적 자료·산술/논리 연산·논리 회로·범용
아날로그 → 연속적 자료·미분/적분 연산·증폭 회로·특수 목적
하이브리드 → 디지털 + 아날로그의 장점 결합

04. 처리 능력에 따른 컴퓨터의 분류와 성능 단위

[컴퓨터의 종류]
- 슈퍼컴퓨터: 매우 빠른 계산 능력으로 대규모·고정밀 계산을 수행한다. 일기예보, 인공위성, 우주·항공 분야 등에 사용한다.
- 메인프레임: 대규모 자료 처리에 사용하는 대형 컴퓨터이다. 수백 명 이상의 사용자가 동시에 이용할 수 있다.
- 미니컴퓨터: 중규모 시스템으로, 학교·연구소 등의 업무 처리와 과학기술 계산에 사용되어 왔다.
- 워크스테이션: 전문적인 작업에 사용하는 고성능 컴퓨터이다. 고성능 그래픽 처리, 과학기술 계산, 네트워크의 서버 역할 등에 사용한다.
- 데스크톱 컴퓨터: 책상 위에 설치하여 사용하는 개인용 컴퓨터(PC)로, 가정·사무실에서 주로 사용한다.
- 휴대용 컴퓨터: 이동하며 사용할 수 있는 컴퓨터이다. 대표적인 예는 노트북이다.

[프로세서 관련 시험 키워드]
- RISC: 단순한 명령어 중심으로 구성한 방식. 전통적인 분류에서 워크스테이션과 연결한다.
- CISC: 복잡하고 다양한 명령어를 제공하는 방식. 전통적인 분류에서 데스크톱 PC와 연결한다.

[컴퓨터의 성능 단위]
- Hz(헤르츠): 1초 동안 주기가 반복되는 횟수. CPU의 클록 주파수 등을 나타낸다.
  1kHz = 초당 1,000회 / 1MHz = 초당 100만 회 / 1GHz = 초당 10억 회
- MIPS: 1초에 실행하는 명령어 수를 100만 개 단위로 나타낸다.
  예: 4MIPS = 1초에 명령어 400만 개 실행.
- FLOPS: 1초에 수행하는 부동소수점 연산 횟수. 과학기술 계산과 슈퍼컴퓨터의 성능을 나타낼 때 사용한다.

※ Hz는 클록의 반복 횟수이므로, 1Hz를 '명령어를 초당 1개 실행한다'는 뜻으로 해석하지 않는다.

[시험 핵심 암기]
슈퍼컴퓨터 → 일기예보·우주항공 / 메인프레임 → 대규모·다수 사용자 / 미니컴퓨터 → 중규모
워크스테이션 → 전문 작업·그래픽·서버·RISC / 데스크톱 → 개인용·CISC
Hz → 주기 / MIPS → 초당 명령어 수(100만 개 단위) / FLOPS → 초당 부동소수점 연산 횟수

05. 정보처리 형태에 따른 분류

[기본 처리 방식]
- 일괄 처리(Batch Processing): 자료를 일정 기간 모아 한꺼번에 처리한다. 예: 월급 계산. 1세대와 연결한다.
- 실시간 처리(Real-time Processing): 자료가 발생하거나 요청되는 즉시 처리하여 결과를 제공한다. 예: 좌석 예약. 2세대·온라인 처리와 연결한다.
- 다중 프로그래밍(Multiprogramming): 여러 프로그램을 메모리에 올려 두고 CPU가 번갈아 처리한다. 입출력 대기 시간을 활용하여 CPU 이용률을 높인다.
- 다중 처리(Multiprocessing): 두 개 이상의 CPU(프로세서)를 이용하여 여러 작업을 동시에 처리한다.
- 분산 처리(Distributed Processing): 통신망으로 연결된 여러 컴퓨터가 작업을 나누어 처리한다. 4세대와 연결한다.

[시스템 구성과 활용]
- 동배간 처리(P2P): 참여하는 컴퓨터가 대등한 관계에서 자원을 주고받는다. 각 컴퓨터가 서버와 클라이언트 역할을 모두 할 수 있다.
- 임베디드 시스템(Embedded System): 기기 안에 컴퓨터와 프로그램을 내장하여 특정 기능을 수행한다. 예: 세탁기 제어 장치.
- 클러스터링(Clustering): 여러 컴퓨터를 연결하여 하나의 시스템처럼 사용한다. 처리 성능과 가용성을 높인다.

[고장에 대비하는 이중화 방식]
- 듀얼 시스템(Dual System): 두 시스템이 동시에 같은 업무를 처리한다. 하나가 고장 나도 다른 하나가 계속 처리한다.
- 듀플렉스 시스템(Duplex System): 한 시스템이 업무를 처리하고 다른 시스템은 대기한다. 고장이 나면 대기하던 시스템이 업무를 이어받는다.

[시험 핵심 암기]
다중 프로그래밍 → 여러 프로그램·CPU 이용률 향상 / 다중 처리 → 여러 CPU·동시 처리
분산 처리 → 작업을 나눔 / 클러스터링 → 여러 컴퓨터를 하나의 시스템처럼 사용
듀얼 → 둘 다 동작 / 듀플렉스 → 하나 동작·하나 대기

06. 자료의 구성 단위

[기본 단위]
- 비트(bit): 0 또는 1을 나타내는 자료 표현의 최소 단위.
- 니블(Nibble): 4비트. 16진수 한 자리를 표현할 수 있다.
- 바이트(Byte): 8비트. 1바이트로 256가지(2의 8제곱)를 표현할 수 있다.
- 워드(Word): CPU가 한 번에 처리하는 기본 단위. 크기는 CPU에 따라 다르다.

[자료를 묶는 단위]
- 필드(Field): 이름·학번 등 하나의 항목을 나타내는 단위.
- 레코드(Record): 관련 필드를 모은 단위. 예: 한 학생의 학번·이름·점수.
- 블록(Block): 저장장치와 자료를 주고받는 물리적 단위. 여러 레코드를 묶어 구성할 수 있다.
- 파일(File): 관련 레코드의 모음. 예: 학생 전체의 성적 파일.
- 데이터베이스(Database): 관련 자료를 통합하여 여러 사용자가 공동으로 활용하도록 구성한 자료의 집합.

※ 자료 구성의 기초 암기 순서: 비트 → 니블 → 바이트 → 워드 → 필드 → 레코드 → 블록 → 파일 → 데이터베이스
※ 위 순서가 모든 단위의 고정된 크기 관계를 뜻하지는 않는다. 워드는 CPU의 처리 단위이고, 블록은 물리적 입출력 단위이다.
※ 문자를 표현하는 데 필요한 바이트 수는 문자 코드에 따라 다르다. 워드는 '단어 한 개'를 뜻하지 않는다.

[시험 핵심 암기]
1니블 = 4비트 / 1바이트 = 8비트 = 2니블
필드 → 항목 / 레코드 → 관련 필드의 모음 / 파일 → 관련 레코드의 모음
레코드 → 논리적 단위 / 블록 → 물리적 입출력 단위 / 워드 → CPU의 기본 처리 단위

07. 컴퓨터의 연산 시간 단위

연산 시간은 한 번의 연산에 걸리는 시간이다. 같은 연산이라면 걸리는 시간이 짧을수록 처리 속도가 빠르다.

[시간 단위: 기준은 초(s)]
- ms(밀리초): 10^-3초 = 1,000분의 1초
- μs(마이크로초): 10^-6초 = 100만분의 1초
- ns(나노초): 10^-9초 = 10억분의 1초
- ps(피코초): 10^-12초 = 1조분의 1초
- fs(펨토초): 10^-15초 = 1,000조분의 1초
- as(아토초): 10^-18초 = 100경분의 1초

[단위 변환]
이웃한 단위끼리는 1,000배 차이가 난다.
1ms = 1,000μs / 1μs = 1,000ns / 1ns = 1,000ps / 1ps = 1,000fs / 1fs = 1,000as
예: 같은 연산을 1μs에 처리하는 컴퓨터는 1ms에 처리하는 컴퓨터보다 1,000배 빠르다.

[시험 핵심 암기]
순서: 밀리 → 마이크로 → 나노 → 피코 → 펨토 → 아토
지수: -3 → -6 → -9 → -12 → -15 → -18
오른쪽으로 갈수록 시간 단위가 작아지고, 같은 연산에 1단위의 시간이 걸린다면 처리 속도는 빨라진다.

08. 문자 표현 코드

문자 코드는 문자·숫자·기호에 고유한 번호를 부여하여 컴퓨터에서 표현하는 약속이다.

- ASCII 코드: 데이터 통신에 사용되는 7비트 코드. 존(Zone) 3비트 + 디지트(Digit) 4비트로 구성하며, 128가지(2^7)를 표현한다. 패리티 비트는 별도이다.
- EBCDIC 코드: BCD를 확장한 8비트 코드. 존 4비트 + 디지트 4비트로 구성하며, 256가지(2^8)를 표현한다.
- 유니코드(Unicode): 세계 여러 나라의 문자를 통일하여 표현하는 국제 표준이다. UTF-8·UTF-16 등의 방식으로 저장한다.
  ※ 모든 문자가 반드시 2바이트인 것은 아니다. UTF-8은 코드 포인트당 1~4바이트, UTF-16은 2바이트 또는 4바이트를 사용한다.
- 완성형 한글 코드: 완성된 한글 음절마다 코드를 부여한다. KS X 1001·정보 교환용을 핵심 키워드로 기억한다.
- 조합형 한글 코드: 초성·중성·종성을 각각 코드로 표현하여 조합한다. 한글의 구성 원리를 반영하며, 정보 처리용과 연결한다.

[시험 핵심 암기]
ASCII → 7비트·128가지 / EBCDIC → 8비트·256가지 / 유니코드 → 국제 표준
완성형 → 음절별 코드 / 조합형 → 초성·중성·종성 조합

09. 오류 검출과 교정

오류 검출은 자료에 오류가 있는지 알아내는 것이고, 오류 교정은 잘못된 비트를 바로잡는 것이다.

- 패리티 검사: 검사 비트 1개를 추가하여 전체 비트 중 1의 개수가 정해진 홀수 또는 짝수가 되도록 한다. 오류 검출만 가능하며 교정은 불가능하다.
  홀수(기수) 패리티 → 1의 총개수를 홀수로 / 짝수(우수) 패리티 → 1의 총개수를 짝수로 맞춘다.
  ※ 총개수에는 패리티 비트도 포함한다. 홀수 개의 비트 오류는 검출하지만, 짝수 개의 비트 오류는 검출하지 못한다.
- 정마크 부호: 코드 안의 1의 개수를 일정하게 유지하는 방식으로, 코드 자체의 규칙을 이용하여 오류를 검출한다.
- 해밍 코드: 여러 패리티 비트를 이용하여 오류를 검출하고 교정한다. 대표적으로 1비트 오류를 교정할 수 있다.
- CRC(순환 중복 검사): 생성 다항식을 이용한 나눗셈의 나머지로 오류를 검사한다. 연속된 비트에 발생하는 오류(버스트 오류) 검출에 효과적이다.
- 블록 합 검사(BSC): 자료를 블록 단위로 검사하여 단순 패리티 검사의 한계를 보완한다.

[시험 핵심 암기]
패리티 → 검출만 가능 / 해밍 → 검출·교정 가능 / CRC → 다항식·버스트 오류 검출

10. 숫자 표현 방식


고정소수점 → 소수점 위치 고정·정수 표현·구조 단순
  예: 12.12,  5.10
부동소수점 → 부호/지수/가수·큰 수와 작은 수·반올림 오차
  예: 1212 × 10^-6

1의 보수 → 0과 1 뒤집기 / 2의 보수 → 뒤집고 1 더하기

10진수 : 0~9
2진수: 0~1

11. 중앙처리장치(CPU)

중앙처리장치(CPU)는 명령어를 해석하고, 계산하며, 컴퓨터의 동작을 제어하는 핵심 장치이다.
- 구성: 제어장치(CU) + 연산장치(ALU) + 레지스터.
- 컴퓨터의 5대 장치: 입력장치·출력장치·기억장치·제어장치·연산장치.

[레지스터(Register)]
CPU 내부에서 명령어·데이터·주소 등을 잠시 저장하는 고속 기억장치이다. 일반적으로 캐시나 주기억장치보다 빠르다.
레지스터의 비트 수는 CPU가 한 번에 처리하는 데이터의 크기인 워드 크기와 관련된다.

[제어장치(CU): 명령 해석과 동작 지시]
프로그램의 명령어를 해석하고, 각 장치에 제어 신호를 보내 작업 순서를 조정한다.
- 프로그램 카운터(PC): 다음에 실행할 명령어의 주소를 기억한다.
- 명령 레지스터(IR): 현재 실행 중인 명령어의 내용을 기억한다.
- 명령 해독기(Decoder): IR에 저장된 명령어를 해석한다.
- 부호기(Encoder): 해석된 명령에 따라 각 장치에 보낼 제어 신호를 생성한다.
- 메모리 주소 레지스터(MAR): 기억장치에서 읽거나 쓸 데이터의 주소를 기억한다.
- 메모리 버퍼 레지스터(MBR): 기억장치에서 읽어 온 데이터나 기록할 데이터를 임시로 기억한다. MDR이라고도 한다.

※ PC와 MAR는 '주소', IR은 '명령어', MBR는 '데이터'를 기억한다.
※ 명령 해독은 명령어가 지시하는 동작을 알아내는 과정이다. 단순히 10진수로 바꾸는 뜻은 아니다.

[연산장치(ALU): 계산과 판단]
덧셈·뺄셈 등의 산술 연산과 AND·OR·NOT 등의 논리 연산을 수행한다.
- 가산기(Adder): 덧셈을 수행한다.
- 보수기(Complementer): 뺄셈에 사용할 보수를 만든다. 컴퓨터는 보수를 이용하여 뺄셈을 덧셈으로 처리한다.
  예: 3 - 1 → 3 + (-1).
- 누산기(Accumulator, AC): 연산의 중간 결과와 최종 결과를 임시로 기억한다.
- 상태 레지스터: 연산 결과의 상태를 기억한다. 올림수(Carry)·영(Zero)·부호(Sign)·오버플로 등을 표시한다.
  PSW(프로그램 상태 워드)는 이러한 상태 정보와 제어 정보 등을 담는다.

[버스(Bus): 데이터가 이동하는 통로]
- 내부 버스: CPU 내부의 레지스터와 각 구성 요소 사이에서 정보를 전달한다.
- 외부 버스: CPU와 기억장치·입출력장치 사이에서 정보를 전달한다.
- 기능에 따른 구분: 데이터 버스(데이터 전달)·주소 버스(위치 지정)·제어 버스(읽기·쓰기 등 제어 신호 전달).

[기억장치의 속도와 CPU 성능]
- 일반적인 접근 속도: 레지스터 > 캐시 메모리 > 주기억장치(DRAM) > 보조기억장치.
- 자기테이프: 순차 접근 방식이며, 주로 대용량 자료의 백업에 사용한다.
- CPU 성능에 영향을 주는 요소: 클럭 주파수·캐시 메모리·워드 크기 등.
  클럭은 동작의 박자, 캐시는 자주 쓰는 자료의 고속 저장 공간, 워드는 한 번에 처리하는 데이터의 기본 단위이다.

[시험 핵심 암기]
CPU = 제어장치 + 연산장치 + 레지스터 / 가장 빠른 기억장치 → 레지스터
PC → 다음 명령어 주소 / IR → 현재 명령어 / MAR → 데이터 주소 / MBR → 데이터
가산기 → 덧셈 / 보수기 → 뺄셈에 이용 / 누산기 → 연산 결과 / 상태 레지스터 → 연산 상태
내부 버스 → CPU 내부 / 외부 버스 → CPU와 외부 장치 사이

12. 마이크로프로세서와 RISC·CISC

마이크로프로세서는 제어장치·연산장치·레지스터 등 CPU의 기능을 하나의 반도체 칩에 집적한 장치이다.
RISC와 CISC는 CPU의 명령어 구성 방식에 따른 구분이다.

[RISC: 단순한 명령어 중심]
- 명령어 종류가 적고 구조가 단순하며, 주소 지정 방식이 간단하다.
- 레지스터가 많고, 전력 소모가 적으며, 명령어 처리 속도가 빠른 편이다.
- 전통적인 시험 분류에서는 서버·워크스테이션과 연결하여 기억한다.

[CISC: 복잡하고 다양한 명령어 중심]
- 명령어 종류가 많고 구조가 복잡하며, 주소 지정 방식이 다양하다.
- 전통적인 비교에서 RISC보다 레지스터가 적고, 전력 소모가 많으며, 명령어 처리 속도가 느린 편이다.
- 전통적인 시험 분류에서는 개인용 컴퓨터(PC)와 연결하여 기억한다.

※ 위 내용은 전통적인 구조 비교이다. 실제 성능·전력 소모는 CPU 설계에 따라 달라지며, 사용 기기만으로 RISC·CISC를 단정하지 않는다.

[시험 핵심 암기]
RISC → 명령어 적음·단순 / 주소 지정 간단 / 레지스터 많음 / 저전력
CISC → 명령어 많음·복잡 / 주소 지정 다양 / 레지스터 적음
명령어 종류의 수와 레지스터의 수를 반대로 기억하지 않도록 주의한다.

13. 주기억장치: ROM과 RAM

주기억장치는 CPU가 처리할 프로그램과 데이터를 저장하는 기억장치이며, 기본적으로 ROM과 RAM으로 구분한다.

[ROM(Read Only Memory)]
- 비휘발성 메모리: 전원을 꺼도 저장 내용이 유지된다.
- 주로 읽기 용도로 사용하며, 부팅에 필요한 기본 프로그램 등을 저장한다.
- 주요 저장 내용: BIOS(기본 입출력 시스템)·POST(전원 투입 시 자가 진단 프로그램)·글꼴(폰트) 등.
  BIOS는 부팅과 기본 입출력을 지원하고, POST는 전원을 켰을 때 하드웨어 이상을 점검한다.

[RAM(Random Access Memory)]
- 휘발성 메모리: 전원을 끄면 저장 내용이 사라진다.
- 읽기와 쓰기가 가능하며, 현재 실행 중인 프로그램과 작업 중인 데이터를 저장한다.
  예: 문서 편집 중인 내용은 RAM에서 처리하므로, 보관하려면 SSD 등 보조기억장치에 저장해야 한다.

[시험 핵심 암기]
ROM → 비휘발성·읽기 중심·BIOS·POST·폰트
RAM → 휘발성·읽기/쓰기·실행 중인 프로그램과 데이터
BIOS → 기본 입출력 / POST → 전원을 켰을 때 자가 진단

14. DRAM과 SRAM의 비교

DRAM과 SRAM은 모두 읽기·쓰기가 가능한 휘발성 RAM이다. 전원을 끄면 저장 내용이 사라진다.

[DRAM(Dynamic RAM, 동적 램)]
- 구성 소자: 콘덴서(커패시터)에 전하를 저장한다.
- 전하가 점차 줄어들므로 주기적인 재충전(Refresh)이 필요하다.
- SRAM보다 속도가 느리지만, 가격이 저렴하고 집적도가 높아 대용량 구성에 유리하다.
- 주요 용도: 주기억장치.

[SRAM(Static RAM, 정적 램)]
- 구성 소자: 플립플롭 회로를 이용한다.
- 전원이 공급되는 동안 내용이 유지되어 재충전이 필요 없다.
- DRAM보다 속도가 빠르지만, 가격이 비싸고 집적도가 낮다.
- 주요 용도: 캐시 메모리.

[시험 핵심 암기]
DRAM → 콘덴서·재충전 필요·저가·고집적·주기억장치
SRAM → 플립플롭·재충전 불필요·고가·고속·캐시 메모리
전력 소모의 전통적인 시험 비교: DRAM은 적음 / SRAM은 많음. 실제 소비 전력은 설계와 동작 조건에 따라 달라진다.
※ SRAM도 휘발성이다. '재충전 불필요'가 '전원을 꺼도 보존'을 뜻하지 않는다.

15. ROM의 종류와 플래시 메모리

- 마스크 ROM(Mask ROM): 제조할 때 내용을 기록하며, 사용자가 수정할 수 없다.
- PROM: 사용자가 한 번 기록할 수 있으며, 기록 후에는 지우거나 수정할 수 없다.
- EPROM: 자외선으로 내용을 지운 뒤 다시 기록할 수 있다.
- EEPROM: 전기적으로 내용을 지우고 다시 기록할 수 있다.
- 플래시 메모리(Flash Memory): EEPROM의 한 종류로, 블록 단위로 내용을 지운다. 전기적으로 여러 번 기록할 수 있는 비휘발성 메모리이다.
  전력 소모가 적고 휴대가 쉬우며, USB 메모리·SD 카드·SSD 등에 사용한다.

[시험 핵심 암기]
마스크 ROM → 제조 시 기록 / PROM → 사용자 1회 기록
EPROM → 자외선 / EEPROM → 전기 / 플래시 → 비휘발성·블록 단위 삭제

16. 캐시 메모리와 가상 메모리

- 캐시 메모리(Cache Memory): CPU와 주기억장치 사이의 속도 차이를 줄이는 고속 메모리이다. 자주 사용하는 명령어와 데이터를 저장하며, 주로 SRAM을 사용한다.
- 가상 메모리(Virtual Memory): SSD·하드디스크 등 보조기억장치의 일부를 활용하여, 실제 RAM보다 큰 메모리 공간을 사용하는 것처럼 만드는 기법이다.
  주기억장치의 용량 부족을 보완하지만, 보조기억장치 접근이 잦아지면 처리 속도가 느려질 수 있다.

[시험 핵심 암기]
캐시 메모리 → 속도 차이 보완·SRAM / 가상 메모리 → 용량 부족 보완·보조기억장치 활용

17. 버퍼 메모리와 연관 메모리

[버퍼 메모리(Buffer Memory)]
데이터를 주고받는 장치 사이의 속도 차이를 보완하기 위해 데이터를 잠시 저장하는 공간이다.
예: 인쇄할 데이터를 버퍼에 모아 두고, 프린터가 처리할 수 있는 속도에 맞춰 전달한다.
복사·잘라내기·붙여넣기에 사용하는 클립보드도 데이터를 임시로 보관하는 공간이다.

[연관 메모리(Associative Memory)]
주소 대신 저장된 내용의 일부를 이용하여 일치하는 데이터를 찾는 기억장치이다. 내용 주소화 기억장치(CAM)라고도 한다.
- 장점: 여러 내용을 병렬로 비교하여 정보 검색이 빠르다.
- 단점: 회로가 복잡하여 하드웨어 비용이 많이 든다.

[시험 핵심 암기]
버퍼 → 임시 저장·장치 간 속도 차이 보완
연관 메모리 → 주소 대신 내용으로 검색·병렬 비교·고속 검색·고비용

18. 펌웨어(Firmware)

하드웨어의 기본 동작을 제어하고 관리하는 소프트웨어이다. 주로 ROM·플래시 메모리 같은 비휘발성 메모리에 저장한다.
예: BIOS, 공유기·프린터의 내부 제어 프로그램.

업데이트 가능한 펌웨어는 하드웨어를 교체하지 않고도 오류를 수정하거나 기능·성능을 개선할 수 있다.

[시험 핵심 암기]
펌웨어 → 하드웨어 제어용 소프트웨어·ROM 등에 저장·업데이트로 기능 개선

19. 보조기억장치와 기억 용량 단위

보조기억장치는 프로그램과 데이터를 장기간 보관하는 비휘발성 저장장치이다. 전원을 꺼도 내용이 유지된다.
- 주기억장치(RAM)보다 일반적으로 속도가 느리지만, 용량이 크고 단위 용량당 가격이 저렴하다.
- 예: 하드디스크(HDD)·SSD·USB 메모리·광디스크·자기테이프.

[기억 용량 단위: 시험의 1,024배 기준]
- 1Byte(바이트, B) = 8bit
- 1KB(킬로바이트) = 1,024B = 2^10B
- 1MB(메가바이트) = 1,024KB = 2^20B
- 1GB(기가바이트) = 1,024MB = 2^30B
- 1TB(테라바이트) = 1,024GB = 2^40B
- 1PB(페타바이트) = 1,024TB = 2^50B
- 1EB(엑사바이트) = 1,024PB = 2^60B

※ 위 표는 교재에서 사용하는 관례이다. 엄밀한 이진 단위 표기는 KiB·MiB·GiB 등이며, 저장장치 제품의 KB·MB·GB 등은 1,000배 기준으로 표시되기도 한다.

20. 디스크 연결 방식

- IDE: 병렬 연결 방식. 한 채널에 최대 2개의 장치를 연결한다.
- EIDE: IDE를 개선한 방식. 일반적으로 2개 채널을 이용하여 총 4개의 장치를 연결한다.
- SCSI(스카시): 하드디스크·CD-ROM·스캐너 등 여러 주변장치를 연결하는 인터페이스이다. 전통적인 8비트 SCSI는 제어기를 제외하고 최대 7개 장치를 연결한다.
- SATA: 직렬 연결 방식. 핫 플러그를 지원하며, 실제 사용하려면 장치·제어기·운영체제 등의 지원이 필요하다.
  핫 플러그(Hot Plug): 전원이 켜진 상태에서 장치를 연결하거나 분리하는 기능.

[시험 핵심 암기]
IDE → 2개 / EIDE → 4개 / 전통적인 SCSI → 7개 / SATA → 직렬·핫 플러그

21. RAID와 데이터 저장 방식

RAID는 여러 디스크를 하나의 논리적 저장장치처럼 구성하는 기술이다. 구성 방식에 따라 처리 속도나 장애 대응 능력을 높인다.

- 스트라이핑(Striping, RAID 0): 데이터를 여러 디스크에 나누어 기록한다. 속도가 빠르지만 복구용 중복 정보가 없어, 한 디스크가 고장 나도 데이터가 손실될 수 있다.
- 미러링(Mirroring, RAID 1): 같은 데이터를 두 디스크에 똑같이 기록한다. 하나가 고장 나도 다른 디스크로 데이터를 유지할 수 있다.
- 패리티(Parity, 대표적으로 RAID 5): 데이터와 함께 복구용 정보를 분산 저장한다. RAID 5는 최소 3개 디스크가 필요하며, 디스크 1개 고장까지 복구할 수 있다.

※ RAID의 효과는 구성 방식에 따라 다르며, RAID 자체가 별도의 백업을 대신하지는 않는다.

[시험 핵심 암기]
RAID 0 → 스트라이핑·속도 향상·장애 복구 불가
미러링 = 동일 복사 / 패리티 = 계산하여 복구

22. SSD·파티션·광디스크

[SSD(Solid State Drive)]
플래시 메모리 등 반도체를 이용하는 비휘발성 저장장치이다. HDD와 달리 회전 원판이나 기계적으로 움직이는 부품이 없다.
- 장점: 데이터 접근과 부팅이 빠르고, 충격에 강하며, 소음·전력 소모가 적다.
- 주의: 부팅 시간이 항상 5초인 것은 아니며, 메모리 셀 불량이나 수명 한계는 발생할 수 있다.

[파티션(Partition)]
하나의 물리적 디스크를 여러 논리적 영역으로 나누는 것이다. 예: 한 디스크를 C:와 D:로 나누어 사용.
각 파티션은 별도로 포맷할 수 있으며, 일반적으로 하나의 파티션에는 하나의 파일 시스템을 사용한다.

[광디스크: 레이저로 데이터를 읽고 기록]
- CD-R: 한 번 기록한 내용은 지우거나 덮어쓸 수 없다. 남은 공간에는 추가 기록이 가능하다.
- DVD: 면수와 층수에 따라 약 4.7~17GB. 대표적으로 단면 1층은 4.7GB, 단면 2층은 8.5GB이다.
- 블루레이(Blu-ray): 청자색 레이저를 사용하며, 고화질 영상 저장에 적합하다. 대표 용량은 1층 25GB·2층 50GB이다.

[시험 핵심 암기]
SSD → 반도체·기계적 구동부 없음 / 파티션 → 물리적 디스크의 논리적 분할
CD-R → 기록 내용 삭제·덮어쓰기 불가 / 블루레이 → 25GB·50GB

23. 입력장치와 출력장치

입력장치는 자료를 컴퓨터에 넣고, 출력장치는 처리 결과를 사용자에게 전달한다.

[주요 입력장치]
- OMR(광학 마크 판독기): 표시된 마크를 읽는다. 예: 객관식 답안지.
- OCR(광학 문자 판독기): 인쇄된 문자를 읽어 문자 데이터로 바꾼다. 예: 공공요금 청구서.
- MICR(자기 잉크 문자 판독기): 자성 잉크로 인쇄한 문자를 읽는다. 예: 수표.
- 디지타이저(Digitizer): 도면의 위치·좌표를 입력한다. 예: 설계도면 입력.
- 그 밖의 장치: 키보드·마우스·트랙볼·스캐너.

[주요 출력장치]
- 프린터: 문자·그림을 종이에 출력한다.
- 플로터(Plotter): 대형 도면 등을 정밀하게 출력한다. 예: 설계도면 출력.
- 모니터: 처리 결과를 화면에 표시하는 표시장치이다.

[시험 핵심 암기]
OMR → 마크 / OCR → 문자 / MICR → 자기 잉크
디지타이저 → 도면 입력 / 플로터 → 도면 출력

24. 모니터의 표시 원리와 성능

- LCD(액정 디스플레이): 전압으로 액정의 배열을 바꾸어 빛의 통과량을 조절한다. 일반적으로 백라이트를 사용한다.
- 픽셀(Pixel, 화소): 화면의 영상을 구성하는 가장 작은 단위이다.
- 해상도: 화면을 구성하는 가로·세로 픽셀 수. 예: 1920 × 1080. 같은 화면 크기에서는 픽셀 수가 많을수록 더 세밀하게 표현한다.
- 색상 수: 표현할 수 있는 색의 개수로, 해상도와 별개의 개념이다.
- 재생률(주사율): 1초에 화면을 갱신하는 횟수이며, 단위는 Hz이다. 예: 60Hz는 초당 60회 갱신. 높을수록 움직임이 부드럽게 보이는 데 유리하다.

[시험 핵심 암기]
픽셀 → 화면의 최소 단위 / 해상도 → 픽셀 수 / 재생률 → 초당 갱신 횟수·Hz

25. 프린터의 속도 단위

- PPM(Pages Per Minute): 1분에 출력하는 페이지 수.
- IPM(Images Per Minute): 1분에 출력하는 이미지 수.
- 3D 프린터의 이동·출력 속도: mm/s(초당 밀리미터)로 나타낸다. 교재에서 MMS로 표기하기도 한다.

※ PPM·IPM은 출력 속도이며, 인쇄의 세밀함을 나타내는 해상도 단위 DPI와 구분한다.

26. 메인보드의 주요 구성 요소

메인보드(Mainboard)는 CPU·메모리·주변장치 등을 연결하는 중심 회로 기판이다.
- 칩셋(Chipset): 각 부품 사이의 데이터 흐름을 제어하는 핵심 반도체들의 집합이다.
- AGP 슬롯: 그래픽카드를 장착하는 전용 슬롯이다. 과거에 사용된 방식으로, 이후 PCI Express(PCIe)가 주로 사용된다.
- ROM BIOS: 컴퓨터를 켤 때 하드웨어를 점검·초기화하고, 운영체제의 부팅을 시작하도록 돕는 기본 입출력 프로그램이다. 비휘발성 메모리에 저장한다.

[시험 핵심 암기]
칩셋 → 부품 간 데이터 흐름 제어 / AGP → 그래픽카드 / ROM BIOS → 초기화·부팅 지원

27. 포트와 주변장치 연결 방식

포트(Port)는 컴퓨터와 주변장치를 연결하여 데이터를 주고받는 접속 부분이다.
- 직렬 포트: 한 전송 경로에서 비트를 순서대로 1비트씩 전송한다.
- 병렬 포트: 여러 비트를 동시에 전송한다. 전통적인 프린터용 병렬 포트는 한 번에 8비트씩 전송한다.
  ※ 같은 조건에서는 병렬이 한 번에 더 많은 비트를 보내지만, 실제 속도는 규격에 따라 달라진다. 직렬 방식이 항상 느린 것은 아니다.
- USB(범용 직렬 버스): 키보드·마우스·저장장치 등을 연결한다. 허브를 이용해 한 USB 버스에 최대 127개의 장치를 연결할 수 있으며, 허브도 개수에 포함한다.
- IEEE 1394(FireWire): 디지털 캠코더 등 멀티미디어 기기를 연결하는 고속 직렬 인터페이스이다.
- IrDA: 적외선을 이용하는 근거리 무선 통신 방식이다.
- HDMI: 하나의 케이블로 디지털 영상과 음성을 함께 전송한다. 예: 모니터·TV·셋톱박스 연결.

[USB 3.x의 핵심 특징]
- USB 3.0의 최대 전송 속도: 5Gbps. USB 3.1 Gen 1도 5Gbps이며, USB 3.1 Gen 2는 10Gbps이다.
- USB 3.0의 Type-A 단자는 흔히 파란색이지만, 색상만으로 규격을 단정하지 않는다.
- 하위 버전과 호환되며, 연결된 장치·포트·케이블 등이 공통으로 지원하는 속도로 동작한다.
- 여러 장치가 같은 전송 대역폭을 공유하면 실제 전송 속도가 느려질 수 있다.

[시험 핵심 암기]
직렬 → 순서대로 / 병렬 → 여러 비트 동시 / USB → 최대 127개
IEEE 1394 → 디지털 캠코더 / IrDA → 적외선 / HDMI → 영상·음성 동시 전송
USB 3.0 → 5Gbps / USB 3.1 Gen 2 → 10Gbps

28. 인터럽트(Interrupt)

CPU가 처리해야 할 사건이 발생했을 때, 진행하던 작업을 잠시 멈추고 해당 사건을 먼저 처리하도록 알리는 신호나 요청이다.
처리 순서: 현재 작업의 상태 저장 → 인터럽트 처리 루틴(ISR) 실행 → 저장한 상태 복원 → 기존 작업 계속.

- 외부 인터럽트: CPU 외부의 장치나 신호에 의해 발생한다.
- 대표 원인: 입출력 작업 완료·타이머 신호·전원 이상.
  예: 디스크 읽기가 끝나면 장치가 CPU에 완료 사실을 인터럽트로 알린다.
- 내부 인터럽트: 명령어 실행 중 잘못된 명령이나 데이터 등으로 발생한다. 예: 0으로 나누기, 잘못된 명령어 실행. 기초 교재에서는 트랩(TRAP)이라고도 부른다.
- SVC(Supervisor Call): 프로그램이 운영체제의 서비스를 요청하기 위해 의도적으로 발생시키는 소프트웨어 인터럽트이다.
- IRQ(Interrupt Request): 입출력장치 등 하드웨어가 CPU에 보내는 인터럽트 요청 신호이다.
- 우선순위: 제시된 교재의 전통적인 분류에서는 정전이 가장 높고, SVC가 가장 낮다. 실제 우선순위는 시스템에 따라 다르다.

[시험 핵심 암기]
인터럽트 → 작업 일시 중단·요청 처리·복귀 / 외부 인터럽트 → 입출력·타이머·전원
내부 인터럽트 → 명령·데이터 오류 / SVC → 의도적인 서비스 요청 / IRQ → 인터럽트 요청 신호

29. 채널(Channel)

CPU로부터 입출력 제어 권한을 받아 CPU 대신 입출력 작업을 관리하는 전용 처리장치이다.
작업이 끝나면 CPU에 인터럽트를 보내 완료 사실을 알린다.

- 셀렉터(Selector) 채널: 한 번에 하나의 고속 입출력장치를 집중적으로 처리한다.
- 멀티플렉서(Multiplexer) 채널: 여러 저속 입출력장치의 데이터를 조금씩 번갈아 처리한다.
- 블록 멀티플렉서(Block Multiplexer) 채널: 여러 고속 입출력장치의 데이터를 블록 단위로 번갈아 처리한다.

[시험 핵심 암기]
채널 → CPU 대신 입출력 관리·완료 시 인터럽트
셀렉터 → 고속·한 장치 / 멀티플렉서 → 저속·여러 장치 / 블록 멀티플렉서 → 고속·블록 단위

30. DMA(Direct Memory Access, 직접 메모리 접근)

CPU가 데이터를 하나씩 옮기지 않고, DMA 제어기가 입출력장치와 주기억장치 사이의 데이터 전송을 직접 수행하는 방식이다.
CPU는 전송 시작에 필요한 정보를 설정하고, 전송이 끝나면 인터럽트로 완료 사실을 전달받는다.

- 효과: CPU의 데이터 전송 부담을 줄여 시스템 성능을 높인다.
- 비교: 채널은 입출력 작업의 제어·관리를 담당하고, DMA는 데이터의 직접 전송에 초점을 둔다.

[시험 핵심 암기]
DMA → 입출력장치 ↔ 주기억장치 직접 전송·CPU 부담 감소
※ 'CPU 참여 없음'은 데이터 전송 과정에 매번 개입하지 않는다는 뜻이다.

31. 교착 상태(Deadlock, 데드락)

여러 프로세스가 서로 상대방이 가진 자원을 기다려 작업을 더 이상 진행하지 못하는 상태이다.
예: A는 프린터를 가진 채 스캐너를 기다리고, B는 스캐너를 가진 채 프린터를 기다린다.

[교착 상태의 발생 조건: 네 가지가 모두 성립]
- 상호 배제: 한 자원을 한 번에 하나의 프로세스만 사용할 수 있다.
- 점유와 대기: 자원을 가진 상태에서 다른 자원을 추가로 기다린다.
- 비선점: 사용 중인 자원을 다른 프로세스가 강제로 빼앗을 수 없다.
- 환형 대기: 프로세스들이 원형으로 연결되어 서로의 자원을 기다린다.

[시험 핵심 암기]
교착 상태 → 서로 자원을 기다려 진행 불가
발생 조건 → 상호 배제·점유와 대기·비선점·환형 대기
예방 → 네 가지 조건 중 하나 이상이 성립하지 않도록 한다.

32. 소프트웨어의 배포 형태와 시험 버전

[배포·이용 형태]
- 애드웨어(Adware): 광고를 보여 주는 대신 무료 또는 낮은 비용으로 이용하게 하는 프로그램이다.
- 셰어웨어(Shareware): 일정 기간이나 일부 기능을 무료로 사용해 본 뒤, 계속 사용하거나 전체 기능을 이용하려면 비용을 지불하는 프로그램이다.
- 프리웨어(Freeware): 사용료 없이 이용하는 프로그램이다. 무료라고 소스 코드까지 공개되는 것은 아니다. 제시된 교재에서는 '공개 소프트웨어'로 표현한다.
- 상용 소프트웨어: 판매 등 영리 목적으로 제공하는 프로그램이다. 시험에서는 주로 비용을 내고 사용하는 프로그램과 연결한다.
- 번들(Bundle): 컴퓨터나 다른 제품을 구매할 때 함께 제공하는 프로그램이다.

[개발·시험·수정 단계]
- 알파(Alpha) 버전: 개발 초기, 주로 개발사 내부에서 기능과 오류를 시험하는 버전이다.
- 베타(Beta) 버전: 정식 출시 전, 외부 사용자 등의 시험을 통해 오류와 개선점을 찾는 버전이다.
- 데모(Demo) 버전: 홍보·시연을 위해 일부 기능만 제공하는 버전이다.
- 트라이얼(Trial) 버전: 일정 기간 등 정해진 조건으로 사용해 보는 체험판이다.
- 패치(Patch) 프로그램: 배포된 프로그램의 오류·보안 문제 등을 수정하는 프로그램이다.

[시험 핵심 암기]
알파 → 내부 시험 / 베타 → 출시 전 사용자 시험 / 패치 → 배포 후 수정
셰어웨어 → 제한적 무료 체험 / 프리웨어 → 무료 사용 / 번들 → 제품에 함께 제공
데모 → 기능 시연 / 트라이얼 → 체험판 / 애드웨어 → 광고

33. 오픈 소스와 프로그램 호환성

- 오픈 소스(Open Source): 소스 코드가 공개되어, 해당 라이선스가 허용하는 범위에서 사용·수정·재배포할 수 있는 소프트웨어이다. 예: 리눅스(Linux).
  무료 사용 여부와 소스 공개 여부는 별개이다. 프리웨어와 오픈 소스를 같은 뜻으로 외우지 않는다.
- 64비트용 프로그램: 일반적으로 32비트 운영체제에서는 실행할 수 없다. 64비트 운영체제와 해당 환경의 지원이 필요하다.

[시험 핵심 암기]
오픈 소스 → 소스 공개·수정·재배포 / 64비트 앱 → 32비트 OS에서 실행 불가

34. 프로그램의 번역과 실행 과정

컴파일 방식의 기본 과정:
원시 프로그램 → [컴파일러] → 목적 프로그램 → [링커] → 로드 모듈 → [로더] → 메모리에 적재 후 실행

- 원시 프로그램(Source Program): 프로그래밍 언어로 작성한 소스 코드이다.
- 컴파일러(Compiler): 원시 프로그램을 번역하여 목적 프로그램을 만든다.
- 목적 프로그램(Object Program): 번역 결과로 만들어진 코드이다. 필요한 다른 코드와의 연결이 남아 있을 수 있다.
- 링커(Linker, 연결 편집기): 목적 프로그램과 필요한 라이브러리 등을 연결하여 실행 가능한 로드 모듈을 만든다.
- 로더(Loader, 적재기): 로드 모듈을 주기억장치에 올리고 실행을 준비한다.

[시험 핵심 암기]
컴파일러 → 번역 / 링커 → 연결 / 로더 → 주기억장치에 적재
순서 → 원시 프로그램 → 목적 프로그램 → 로드 모듈 → 실행

35. 주요 프로그래밍 언어

- 자바(Java): 객체지향 언어로, 네트워크·분산 환경의 프로그램 개발에 활용한다. 소스를 바이트코드로 번역하며, JVM(자바 가상 머신)이 있는 환경에서 실행하므로 이식성이 높다.
  핵심: 객체지향·바이트코드·JVM·플랫폼 독립성.
- C언어: UNIX 운영체제 개발에 사용된 언어이다. 구조적 프로그래밍을 지원하며, 고급언어이면서 메모리·하드웨어를 세밀하게 다루는 저급언어의 특징도 갖는다. 영문 대문자와 소문자를 구별한다.
  핵심: UNIX·구조적 프로그래밍·하드웨어 제어·대소문자 구별.
- C++: C언어를 확장하여 클래스·상속 등 객체지향 기능을 추가한 언어이다.
  핵심: C언어 확장·객체지향.

36. 구조적 프로그래밍과 객체지향 프로그래밍

[구조적 프로그래밍]
프로그램을 순서·선택·반복의 세 가지 기본 제어 구조로 작성하는 방식이다. 각 기본 구조는 진입점과 종료점이 하나씩이다.
- 순서: 명령을 차례대로 실행한다.
- 선택: 조건에 따라 실행할 내용을 고른다.
- 반복: 조건이나 횟수에 따라 같은 처리를 되풀이한다.
- 대표 언어: C·Pascal·Ada.

[객체지향 프로그래밍(OOP)]
데이터와 그 데이터를 처리하는 동작을 객체로 묶고, 객체들이 서로 상호작용하도록 프로그램을 구성하는 방식이다.
대표 언어: Smalltalk·C++·Java.

- 추상화: 복잡한 대상에서 필요한 핵심 특징만 뽑아 표현한다.
- 캡슐화·정보 은폐: 데이터와 동작을 하나로 묶고, 내부 구현을 감추어 정해진 방법으로 접근하게 한다.
- 상속성·계층성: 기존 클래스의 특징을 물려받아 새 클래스를 만들며, 클래스 간 계층을 구성한다.
- 다형성: 같은 요청이라도 객체의 종류에 따라 다르게 동작한다.
- 모듈성·재사용성: 기능을 독립적인 단위로 구성하고, 기존 구성 요소를 다시 활용한다.
- 오버로딩(Overloading): 같은 이름의 메서드를 매개변수의 개수·자료형 등을 달리하여 정의한다. 다형성과 관련된 개념이다.

기존 클래스와 구성 요소를 재사용하면 프로그램 개발 시간과 유지보수 부담을 줄일 수 있다.

[시험 핵심 암기]
구조적 → 순서·선택·반복 / 객체지향 → 객체 중심·추상화·캡슐화·상속·다형성·재사용
Java → JVM·바이트코드 / C → UNIX·구조적 / C++ → C + 객체지향

37. 비주얼 프로그래밍(Visual Programming)

버튼·창 등의 시각적 요소를 화면에 배치하고 속성과 동작을 설정하여 프로그램을 만드는 방식이다.
화면을 보며 설계하므로 사용자 인터페이스(GUI)를 만들기 쉽다. 필요한 동작은 코드로 작성할 수도 있다.
관련 개발 도구: Visual Studio·Delphi·PowerBuilder.

[시험 핵심 암기]
비주얼 프로그래밍 → 시각적 요소·GUI 설계 / 개발 도구와 프로그래밍 언어를 구분한다.

38. 웹 관련 언어

- HTML5: 태그로 웹 문서의 구조를 표현하는 마크업 언어이다. 오디오·비디오·캔버스 등을 지원하여 ActiveX 같은 별도 플러그인 없이도 멀티미디어를 구현할 수 있다.
- DHTML(Dynamic HTML): HTML·CSS·JavaScript·DOM 등을 함께 이용해 웹페이지의 내용과 모양을 동적으로 바꾸는 기술이다. 독립된 하나의 언어는 아니다.
  예: 메뉴 펼치기, 입력에 따라 화면 내용 바꾸기.
- SGML: 전자문서의 구조와 태그 규칙을 정의하는 범용 마크업 체계이다. 표현력이 풍부하지만 구조와 사용법이 복잡하다.
- XML: SGML을 단순화한 확장 가능한 마크업 언어이다. 사용자가 태그를 정의할 수 있으며, 데이터의 구조 표현·저장·교환에 사용한다.
- WML: XML을 기반으로 한 마크업 언어로, 과거 WAP 방식의 휴대전화 등 무선 단말기에서 사용했다.
- VRML: 웹에서 3차원 객체와 가상 공간을 표현하는 가상현실 모델링 언어이다. 예: 가상 모델하우스.
- Perl: 문자열 처리에 강한 스크립트 언어이다. 웹 서버의 CGI 프로그램 등에 활용되며, 해당 인터프리터가 있으면 여러 운영체제에서 사용할 수 있다.

[시험 핵심 암기]
HTML5 → 웹 문서·멀티미디어 / DHTML → 동적인 웹페이지
SGML → 범용 문서 구조·복잡함 / XML → 사용자 정의 태그·데이터 교환
WML → XML 기반·무선 단말기 / VRML → 3차원 가상 공간 / Perl → 문자열 처리
※ HTML은 문서의 구조와 표시를 위한 기반이고, XML은 데이터의 의미와 구조를 표현하는 데 중점을 둔다.

39. UML(Unified Modeling Language)

소프트웨어의 구조와 동작을 그림으로 표현하는 통합 모델링 언어이다. 설계 내용을 개발자들이 공통된 방식으로 이해하도록 돕는다.
예: 클래스 다이어그램(클래스의 구조·관계), 유스케이스 다이어그램(사용자와 시스템의 기능 관계).

[시험 핵심 암기]
UML → 소프트웨어 설계·모델링 / VRML → 3차원 가상현실 표현
※ UML은 프로그램을 실행하는 언어가 아니라, 시스템을 분석·설계할 때 사용하는 모델링 언어이다.

40. 서버용 웹 기술과 JavaScript

[ASP와 JSP: 서버에서 처리]
사용자의 요청을 서버에서 처리하고, 처리 결과를 웹페이지로 만들어 브라우저에 전달하는 기술이다.
- ASP(Active Server Pages): 마이크로소프트의 서버 측 웹 기술이다. 전통적인 ASP는 주로 Windows의 IIS 웹 서버 환경에서 사용한다.
- JSP(JavaServer Pages): Java 기반의 서버 측 웹 기술이다. 실행 환경이 갖추어지면 여러 운영체제에서 사용할 수 있다.
  예: 서버가 로그인 정보를 확인한 뒤 결과 화면을 보내 준다.

[JavaScript: 웹페이지의 동작 구현]
사용자의 클릭·입력 등에 반응하여 화면을 바꾸는 데 사용하는 스크립트 언어이다.
- 브라우저의 실행 엔진으로 동작하므로 별도 플러그인 없이 사용할 수 있다.
- 대표 활용: 입력값 검사·버튼 동작·웹페이지 내용 변경.
- 브라우저뿐 아니라 서버 환경에서도 사용할 수 있다. Java와는 서로 다른 언어이다.

[시험 핵심 암기]
ASP → 서버 측·Microsoft·Windows/IIS / JSP → 서버 측·Java 기반
JavaScript → 사용자 입력 반응·브라우저 실행·별도 플러그인 불필요

41. Python·LISP·Prolog

- Python(파이썬): 문법이 간결하고 대화형 실행을 지원하는 인터프리터 언어이다. 객체지향 기능을 지원하며, 해당 실행 환경이 있으면 여러 운영체제에서 사용할 수 있다.
- LISP(리스프): 인공지능 분야에 활용된 언어로, 리스트를 기본 자료구조로 사용하며 재귀 호출을 많이 이용한다.
  재귀 호출: 함수가 자기 자신을 다시 호출하여 문제를 해결하는 방식이다.
- Prolog(프롤로그): 인공지능 분야에 활용되는 논리형 언어이다. 사실과 규칙을 작성하고, 논리적 추론으로 질문의 답을 구한다.

[시험 핵심 암기]
Python → 간결한 문법·대화형·인터프리터·객체지향
LISP → 리스트·재귀 호출 / Prolog → 사실과 규칙·논리적 추론
