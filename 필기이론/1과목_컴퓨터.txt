1. 컴퓨터 일반

01. 컴퓨터의 개념과 특징

컴퓨터(EDPS)는 입력된 자료(Data)를 정해진 절차에 따라 처리하여 유용한 정보(Information)로 바꾸는 장치이다.
예: 학생들의 점수(자료)를 계산하여 학급 평균(정보)을 구한다.

[컴퓨터의 주요 특징]
- 자동성: 프로그램에 따라 작업을 자동으로 처리한다.
- 정확성: 주어진 자료와 명령에 따라 정확하게 처리한다.
- 범용성: 계산, 문서 작성 등 다양한 작업에 활용한다.
- 신속성: 많은 자료를 빠르게 처리한다.
- 호환성: 다른 기기나 프로그램과 자료를 주고받거나 함께 사용할 수 있다.
- 대용량성: 많은 자료를 저장하고 처리한다.

[초기 컴퓨터의 구분]
- 에니악(ENIAC): 초기의 대표적인 전자식 컴퓨터. 프로그램 외장 방식으로, 배선과 스위치를 바꾸어 작업을 지정했다.
- 에드삭(EDSAC): 최초의 실용적인 프로그램 내장 방식 컴퓨터. 프로그램을 기억장치에 저장하여 실행했다.
- 에드박(EDVAC): 프로그램 내장 방식과 2진법을 채택한 컴퓨터. 폰 노이만과 관련된다.
- 유니박(UNIVAC): 최초의 상업용 컴퓨터.

※ 프로그램 외장 방식: 프로그램을 배선·스위치 등으로 설정한다.
※ 프로그램 내장 방식: 프로그램을 기억장치에 저장하고, 명령을 차례로 꺼내 실행한다.

[GIGO와 수동성]
GIGO(Garbage In, Garbage Out)는 잘못된 자료를 입력하면 잘못된 결과가 나온다는 뜻이다.
컴퓨터는 입력된 자료와 명령에 따라 작동하므로, 자료의 오류를 스스로 모두 판단하여 고치지는 못한다. 이를 수동성과 연결하여 기억한다.

[시험 핵심 암기]
ENIAC → 프로그램 외장 / EDSAC → 프로그램 내장 / EDVAC → 내장·2진법·폰 노이만 / UNIVAC → 상업용
GIGO → 잘못된 입력은 잘못된 출력으로 이어짐 → 수동성

02. 컴퓨터의 세대별 특징

컴퓨터의 세대는 주요 전자 소자의 발전에 따라 구분한다. 소자가 작아지고 집적도가 높아지면서 컴퓨터도 소형화·고속화되었다.

[1세대: 진공관]
- 주요 소자: 진공관. 기억장치로 자기드럼 등을 사용했다.
- 기계어를 사용했으며, 하드웨어 개발에 중점을 두었다.
- 일괄 처리: 자료를 모아 한꺼번에 처리한다. 오프라인 방식이 중심이었다.

[2세대: 트랜지스터(TR)]
- 고급언어와 운영체제(OS)를 도입했다.
- 온라인 실시간 처리: 통신으로 연결하여 자료가 들어오면 즉시 처리한다.
- 다중 프로그래밍: 여러 프로그램을 메모리에 올려 두고, 한 프로그램이 입출력을 기다리면 다른 프로그램을 실행한다.

[3세대: 집적회로(IC)]
- 시분할 처리(TSS): CPU 시간을 잘게 나누어 여러 사용자에게 번갈아 제공한다.
- 문자·표식 인식 기술 활용: OCR(광학 문자 판독), OMR(광학 마크 판독), MICR(자기 잉크 문자 판독).
- 경영정보시스템(MIS): 경영자의 의사 결정에 필요한 정보를 제공한다.

[4세대: 고밀도 집적회로(LSI)]
- 개인용 컴퓨터(PC)가 보급되고 네트워크가 발달했다.
- 분산 처리: 여러 컴퓨터가 작업을 나누어 처리한다.

[5세대: 초고밀도 집적회로(VLSI)]
- 인터넷과 인공지능(AI)이 발달했다.
- 퍼지 이론: '조금 덥다'처럼 애매한 정도를 다룬다.
- 전문가 시스템: 전문가의 지식과 추론 방법을 이용하여 문제 해결을 돕는다.

[시험 핵심 암기]
소자 순서: 진공관 → 트랜지스터(TR) → 집적회로(IC) → 고밀도 집적회로(LSI) → 초고밀도 집적회로(VLSI)
세대 연결: 1세대 기계어·일괄 처리 / 2세대 고급언어·OS·다중 프로그래밍 / 3세대 시분할·MIS / 4세대 PC·분산 처리 / 5세대 AI·전문가 시스템

03. 처리하는 자료에 따른 컴퓨터의 분류

[디지털 컴퓨터]
숫자나 문자처럼 구분되는 비연속적(이산적) 자료를 처리한다. 내부에서는 자료를 0과 1로 표현한다.
예: 인원수, 상품 수량 등을 계산하는 개인용 컴퓨터(PC).

[아날로그 컴퓨터]
온도·전류·속도처럼 연속적으로 변하는 물리량을 처리한다. 주로 과학·군사 분야의 특수 목적에 사용한다.
예: 전압의 연속적인 변화를 이용하여 물리 현상을 모의 계산한다.

[하이브리드 컴퓨터]
디지털과 아날로그 컴퓨터의 장점을 결합한 컴퓨터이다. 디지털의 정밀한 계산·논리 처리와 아날로그의 연속량 처리를 함께 활용한다.

[디지털과 아날로그의 핵심 비교]
비교 항목: 디지털 / 아날로그
- 입력: 숫자·문자로 표현한 이산적 자료 / 연속적으로 변하는 물리량
- 출력: 주로 숫자·문자 / 주로 그래프 등 연속적인 결과
- 연산: 산술·논리 연산 / 미분·적분 연산
- 구성 회로: 논리 회로 / 증폭 회로
- 프로그래밍: 명령을 작성하여 실행 / 회로 연결·설정으로 계산 수행
- 정밀도: 자릿수를 늘려 필요한 수준까지 높일 수 있음 / 회로·측정 장치의 정밀도에 제한됨
- 기억 기능: 있음 / 일반적으로 없음
- 적용 분야: 범용(개인용 등) / 특수 목적용(과학용·군사용 등)

※ 미분은 변화율을 구하는 것, 적분은 변화량을 누적하여 합하는 것이다.
※ 시험의 기본 비교에서 프로그램은 디지털은 '필요', 아날로그는 '불필요'로 구분한다.

[시험 핵심 암기]
디지털 → 비연속·이산적 자료·산술/논리 연산·논리 회로·범용
아날로그 → 연속적 자료·미분/적분 연산·증폭 회로·특수 목적
하이브리드 → 디지털 + 아날로그의 장점 결합

04. 처리 능력에 따른 컴퓨터의 분류와 성능 단위

[컴퓨터의 종류]
- 슈퍼컴퓨터: 매우 빠른 계산 능력으로 대규모·고정밀 계산을 수행한다. 일기예보, 인공위성, 우주·항공 분야 등에 사용한다.
- 메인프레임: 대규모 자료 처리에 사용하는 대형 컴퓨터이다. 수백 명 이상의 사용자가 동시에 이용할 수 있다.
- 미니컴퓨터: 중규모 시스템으로, 학교·연구소 등의 업무 처리와 과학기술 계산에 사용되어 왔다.
- 워크스테이션: 전문적인 작업에 사용하는 고성능 컴퓨터이다. 고성능 그래픽 처리, 과학기술 계산, 네트워크의 서버 역할 등에 사용한다.
- 데스크톱 컴퓨터: 책상 위에 설치하여 사용하는 개인용 컴퓨터(PC)로, 가정·사무실에서 주로 사용한다.
- 휴대용 컴퓨터: 이동하며 사용할 수 있는 컴퓨터이다. 대표적인 예는 노트북이다.

[프로세서 관련 시험 키워드]
- RISC: 단순한 명령어 중심으로 구성한 방식. 전통적인 분류에서 워크스테이션과 연결한다.
- CISC: 복잡하고 다양한 명령어를 제공하는 방식. 전통적인 분류에서 데스크톱 PC와 연결한다.

[컴퓨터의 성능 단위]
- Hz(헤르츠): 1초 동안 주기가 반복되는 횟수. CPU의 클록 주파수 등을 나타낸다.
  1kHz = 초당 1,000회 / 1MHz = 초당 100만 회 / 1GHz = 초당 10억 회
- MIPS: 1초에 실행하는 명령어 수를 100만 개 단위로 나타낸다.
  예: 4MIPS = 1초에 명령어 400만 개 실행.
- FLOPS: 1초에 수행하는 부동소수점 연산 횟수. 과학기술 계산과 슈퍼컴퓨터의 성능을 나타낼 때 사용한다.

※ Hz는 클록의 반복 횟수이므로, 1Hz를 '명령어를 초당 1개 실행한다'는 뜻으로 해석하지 않는다.

[시험 핵심 암기]
슈퍼컴퓨터 → 일기예보·우주항공 / 메인프레임 → 대규모·다수 사용자 / 미니컴퓨터 → 중규모
워크스테이션 → 전문 작업·그래픽·서버·RISC / 데스크톱 → 개인용·CISC
Hz → 주기 / MIPS → 초당 명령어 수(100만 개 단위) / FLOPS → 초당 부동소수점 연산 횟수

05. 정보처리 형태에 따른 분류

[기본 처리 방식]
- 일괄 처리(Batch Processing): 자료를 일정 기간 모아 한꺼번에 처리한다. 예: 월급 계산. 1세대와 연결한다.
- 실시간 처리(Real-time Processing): 자료가 발생하거나 요청되는 즉시 처리하여 결과를 제공한다. 예: 좌석 예약. 2세대·온라인 처리와 연결한다.
- 다중 프로그래밍(Multiprogramming): 여러 프로그램을 메모리에 올려 두고 CPU가 번갈아 처리한다. 입출력 대기 시간을 활용하여 CPU 이용률을 높인다.
- 다중 처리(Multiprocessing): 두 개 이상의 CPU(프로세서)를 이용하여 여러 작업을 동시에 처리한다.
- 분산 처리(Distributed Processing): 통신망으로 연결된 여러 컴퓨터가 작업을 나누어 처리한다. 4세대와 연결한다.

[시스템 구성과 활용]
- 동배간 처리(P2P): 참여하는 컴퓨터가 대등한 관계에서 자원을 주고받는다. 각 컴퓨터가 서버와 클라이언트 역할을 모두 할 수 있다.
- 임베디드 시스템(Embedded System): 기기 안에 컴퓨터와 프로그램을 내장하여 특정 기능을 수행한다. 예: 세탁기 제어 장치.
- 클러스터링(Clustering): 여러 컴퓨터를 연결하여 하나의 시스템처럼 사용한다. 처리 성능과 가용성을 높인다.

[고장에 대비하는 이중화 방식]
- 듀얼 시스템(Dual System): 두 시스템이 동시에 같은 업무를 처리한다. 하나가 고장 나도 다른 하나가 계속 처리한다.
- 듀플렉스 시스템(Duplex System): 한 시스템이 업무를 처리하고 다른 시스템은 대기한다. 고장이 나면 대기하던 시스템이 업무를 이어받는다.

[시험 핵심 암기]
다중 프로그래밍 → 여러 프로그램·CPU 이용률 향상 / 다중 처리 → 여러 CPU·동시 처리
분산 처리 → 작업을 나눔 / 클러스터링 → 여러 컴퓨터를 하나의 시스템처럼 사용
듀얼 → 둘 다 동작 / 듀플렉스 → 하나 동작·하나 대기

06. 자료의 구성 단위

[기본 단위]
- 비트(bit): 0 또는 1을 나타내는 자료 표현의 최소 단위.
- 니블(Nibble): 4비트. 16진수 한 자리를 표현할 수 있다.
- 바이트(Byte): 8비트. 1바이트로 256가지(2의 8제곱)를 표현할 수 있다.
- 워드(Word): CPU가 한 번에 처리하는 기본 단위. 크기는 CPU에 따라 다르다.

[자료를 묶는 단위]
- 필드(Field): 이름·학번 등 하나의 항목을 나타내는 단위.
- 레코드(Record): 관련 필드를 모은 단위. 예: 한 학생의 학번·이름·점수.
- 블록(Block): 저장장치와 자료를 주고받는 물리적 단위. 여러 레코드를 묶어 구성할 수 있다.
- 파일(File): 관련 레코드의 모음. 예: 학생 전체의 성적 파일.
- 데이터베이스(Database): 관련 자료를 통합하여 여러 사용자가 공동으로 활용하도록 구성한 자료의 집합.

※ 자료 구성의 기초 암기 순서: 비트 → 니블 → 바이트 → 워드 → 필드 → 레코드 → 블록 → 파일 → 데이터베이스
※ 위 순서가 모든 단위의 고정된 크기 관계를 뜻하지는 않는다. 워드는 CPU의 처리 단위이고, 블록은 물리적 입출력 단위이다.
※ 문자를 표현하는 데 필요한 바이트 수는 문자 코드에 따라 다르다. 워드는 '단어 한 개'를 뜻하지 않는다.

[시험 핵심 암기]
1니블 = 4비트 / 1바이트 = 8비트 = 2니블
필드 → 항목 / 레코드 → 관련 필드의 모음 / 파일 → 관련 레코드의 모음
레코드 → 논리적 단위 / 블록 → 물리적 입출력 단위 / 워드 → CPU의 기본 처리 단위

07. 컴퓨터의 연산 시간 단위

연산 시간은 한 번의 연산에 걸리는 시간이다. 같은 연산이라면 걸리는 시간이 짧을수록 처리 속도가 빠르다.

[시간 단위: 기준은 초(s)]
- ms(밀리초): 10^-3초 = 1,000분의 1초
- μs(마이크로초): 10^-6초 = 100만분의 1초
- ns(나노초): 10^-9초 = 10억분의 1초
- ps(피코초): 10^-12초 = 1조분의 1초
- fs(펨토초): 10^-15초 = 1,000조분의 1초
- as(아토초): 10^-18초 = 100경분의 1초

[단위 변환]
이웃한 단위끼리는 1,000배 차이가 난다.
1ms = 1,000μs / 1μs = 1,000ns / 1ns = 1,000ps / 1ps = 1,000fs / 1fs = 1,000as
예: 같은 연산을 1μs에 처리하는 컴퓨터는 1ms에 처리하는 컴퓨터보다 1,000배 빠르다.

[시험 핵심 암기]
순서: 밀리 → 마이크로 → 나노 → 피코 → 펨토 → 아토
지수: -3 → -6 → -9 → -12 → -15 → -18
오른쪽으로 갈수록 시간 단위가 작아지고, 같은 연산에 1단위의 시간이 걸린다면 처리 속도는 빨라진다.

08. 문자 표현 코드

문자 코드는 문자·숫자·기호에 고유한 번호를 부여하여 컴퓨터에서 표현하는 약속이다.

- ASCII 코드: 데이터 통신에 사용되는 7비트 코드. 존(Zone) 3비트 + 디지트(Digit) 4비트로 구성하며, 128가지(2^7)를 표현한다. 패리티 비트는 별도이다.
- EBCDIC 코드: BCD를 확장한 8비트 코드. 존 4비트 + 디지트 4비트로 구성하며, 256가지(2^8)를 표현한다.
- 유니코드(Unicode): 세계 여러 나라의 문자를 통일하여 표현하는 국제 표준이다. UTF-8·UTF-16 등의 방식으로 저장한다.
  ※ 모든 문자가 반드시 2바이트인 것은 아니다. UTF-8은 코드 포인트당 1~4바이트, UTF-16은 2바이트 또는 4바이트를 사용한다.
- 완성형 한글 코드: 완성된 한글 음절마다 코드를 부여한다. KS X 1001·정보 교환용을 핵심 키워드로 기억한다.
- 조합형 한글 코드: 초성·중성·종성을 각각 코드로 표현하여 조합한다. 한글의 구성 원리를 반영하며, 정보 처리용과 연결한다.

[시험 핵심 암기]
ASCII → 7비트·128가지 / EBCDIC → 8비트·256가지 / 유니코드 → 국제 표준
완성형 → 음절별 코드 / 조합형 → 초성·중성·종성 조합

09. 오류 검출과 교정

오류 검출은 자료에 오류가 있는지 알아내는 것이고, 오류 교정은 잘못된 비트를 바로잡는 것이다.

- 패리티 검사: 검사 비트 1개를 추가하여 전체 비트 중 1의 개수가 정해진 홀수 또는 짝수가 되도록 한다. 오류 검출만 가능하며 교정은 불가능하다.
  홀수(기수) 패리티 → 1의 총개수를 홀수로 / 짝수(우수) 패리티 → 1의 총개수를 짝수로 맞춘다.
  ※ 총개수에는 패리티 비트도 포함한다. 홀수 개의 비트 오류는 검출하지만, 짝수 개의 비트 오류는 검출하지 못한다.
- 정마크 부호: 코드 안의 1의 개수를 일정하게 유지하는 방식으로, 코드 자체의 규칙을 이용하여 오류를 검출한다.
- 해밍 코드: 여러 패리티 비트를 이용하여 오류를 검출하고 교정한다. 대표적으로 1비트 오류를 교정할 수 있다.
- CRC(순환 중복 검사): 생성 다항식을 이용한 나눗셈의 나머지로 오류를 검사한다. 연속된 비트에 발생하는 오류(버스트 오류) 검출에 효과적이다.
- 블록 합 검사(BSC): 자료를 블록 단위로 검사하여 단순 패리티 검사의 한계를 보완한다.

[시험 핵심 암기]
패리티 → 검출만 가능 / 해밍 → 검출·교정 가능 / CRC → 다항식·버스트 오류 검출

10. 숫자 표현 방식


고정소수점 → 소수점 위치 고정·정수 표현·구조 단순
  예: 12.12,  5.10
부동소수점 → 부호/지수/가수·큰 수와 작은 수·반올림 오차
  예: 1212 × 10^-6

1의 보수 → 0과 1 뒤집기 / 2의 보수 → 뒤집고 1 더하기

10진수 : 0~9
2진수: 0~1
