2. 운영체제(Windows 10)

01. 운영체제의 개념과 기본 기능

운영체제(OS)는 하드웨어·소프트웨어 자원을 효율적으로 관리하고, 사용자가 컴퓨터를 편리하게 이용하도록 돕는 시스템 소프트웨어이다.

[운영체제의 목적]
- 처리능력(Throughput) 향상: 일정 시간 동안 처리하는 작업의 양을 늘린다.
- 응답시간(Turnaround Time) 단축: 작업을 요청한 뒤 결과를 얻기까지 걸리는 시간을 줄인다. 이 영문 용어는 '반환시간'이라고도 한다.
- 사용가능도(Availability) 증대: 필요할 때 시스템을 사용할 수 있는 정도를 높인다.
- 신뢰도(Reliability) 향상: 주어진 작업을 정확하게 처리하는 정도를 높인다.
※ 사용가능도는 '얼마나 빨리 처리하는가'보다 '필요할 때 사용할 수 있는가'에 초점을 둔다.

[운영체제의 구성]
- 제어 프로그램: 시스템의 실행과 자원을 관리한다. 감시 프로그램·작업 관리 프로그램·데이터 관리 프로그램으로 구분한다.
- 처리 프로그램: 실제 자료 처리와 사용자 작업을 수행한다. 언어 번역 프로그램·서비스 프로그램·문제 처리 프로그램으로 구분한다.
  언어 번역 → 소스 코드 번역 / 서비스 → 정렬·병합 등 공통 기능 / 문제 처리 → 사용자의 업무 해결.

[처리 방식의 발전 순서]
일괄 처리 → 실시간 처리 → 다중 프로그래밍 → 시분할 처리 → 다중 처리 → 분산 처리 시스템
- 일괄 처리: 자료를 모아 한꺼번에 처리한다.
- 실시간 처리: 자료나 요청이 발생하면 즉시 처리한다.
- 다중 프로그래밍: 여러 프로그램을 메모리에 올려 두고, 입출력 대기 중 다른 프로그램을 실행하여 CPU 이용률을 높인다.
- 시분할 처리: CPU 시간을 잘게 나누어 여러 사용자나 작업에 번갈아 배정한다.
- 다중 처리: 두 개 이상의 프로세서로 작업을 동시에 처리한다.
- 분산 처리: 통신망으로 연결된 여러 컴퓨터가 작업을 나누어 처리한다.

[부팅 과정]
부팅은 전원을 켠 뒤 운영체제를 메모리에 올려 사용할 수 있도록 준비하는 과정이다.
전통적인 BIOS·MBR 방식의 핵심 흐름:
ROM BIOS 실행·CMOS 설정 확인 → POST(전원 켤 때 하드웨어 자가진단) → MBR·부트 섹터 → 부팅 관리자·로더 → 커널 적재 → Windows 로그온 → Explorer.exe 실행(바탕화면 표시)
- 커널(Kernel): CPU·메모리 등 핵심 자원을 관리하는 운영체제의 중심 부분이다.
※ 부팅 방식에 따라 세부 과정은 다르며, UEFI·GPT 방식에서는 MBR 부팅 코드를 사용하지 않는다.

[진단 모드와 다중 스레드]
- 진단 모드: 기본 장치와 서비스만으로 Windows를 시작하여 문제의 원인을 확인하는 시작 방식이다. 시스템 구성(msconfig)에서 설정한다.
- 스레드(Thread): 프로세스 안에서 CPU가 실행하는 작업의 단위이다.
- 다중 스레드(Multithreading): 하나의 프로세스 안에서 여러 스레드가 작업을 나누어 수행하는 방식이다.
  예: 한 프로그램에서 화면 표시와 파일 다운로드를 나누어 처리한다.
※ 다중 처리 → 여러 프로세서 / 다중 스레드 → 한 프로세스 안의 여러 실행 흐름.

[시험 핵심 암기]
OS 목적 → 처리능력↑·응답시간↓·사용가능도↑·신뢰도↑
제어 프로그램 → 감시·작업 관리·데이터 관리 / 처리 프로그램 → 언어 번역·서비스·문제 처리
POST → 하드웨어 자가진단 / 커널 → OS 핵심 / Explorer.exe → 바탕화면 표시
진단 모드 → 기본 장치·서비스로 시작 / 다중 스레드 → 한 프로세스·여러 스레드

02. 한글 Windows 10의 특징

[사용 환경과 작업 처리]
- GUI(그래픽 사용자 인터페이스): 창·아이콘·메뉴 등을 마우스로 조작하는 방식이다. DOS는 명령어를 입력하는 CUI(문자 사용자 인터페이스) 방식이다.
- 선점형 멀티태스킹: 운영체제가 각 작업의 CPU 사용 시간을 제어하여 여러 작업을 번갈아 실행한다. 응답하지 않는 프로그램은 작업 관리자에서 종료할 수 있다.
- Windows 10은 32비트(x86) 버전과 64비트(x64) 버전이 있다. 모두 64비트인 것은 아니다.

[하드웨어 연결]
- 플러그 앤 플레이(PnP): 새 하드웨어를 연결하면 자동으로 인식하고 필요한 설정을 하는 기능이다. 장치에 따라 드라이버 설치가 필요하다.
- 자동 인식이 안 될 때: Win+R → hdwwiz 입력 → 하드웨어 추가 마법사 실행.
- 핫 스왑(Hot Swap): 전원을 켠 상태에서 지원되는 장치를 연결하거나 분리하는 기능이다.
※ PnP → 자동 인식·설정 / 핫 스왑 → 전원을 끄지 않고 연결·분리.

[OLE: 개체 연결 및 삽입]
다른 프로그램에서 만든 표·그림 등의 개체를 문서에 넣어 사용하는 기능이다.
- 연결(Link): 원본과 연결하여, 원본이 바뀌면 문서의 연결 개체에도 반영할 수 있다.
- 삽입/포함(Embed): 개체를 문서 안에 저장한다. 원본 파일을 수정해도 자동으로 바뀌지 않는다.
예: Excel 표를 다른 문서에 '연결'하면 원본 표의 변경 내용을 반영할 수 있다.

[파일 이름과 NTFS]
- 파일 이름: 일반적으로 확장자와 점을 포함해 최대 255자이며, 공백도 사용할 수 있다.
- 사용할 수 없는 문자: \ / : * ? " < > |
- NTFS: Windows의 대표적인 파일 시스템이다. 대용량 저장장치, 파일·폴더 접근 권한, 압축·암호화, 파일 시스템 오류의 자동 복구를 지원한다.
※ 자동 복구는 파일 시스템의 일관성을 유지하는 기능이며, 삭제한 파일이나 물리적으로 고장 난 디스크를 모두 복구한다는 뜻은 아니다.
※ 이미지의 '볼륨 256TB·파일 16TB'는 모든 환경의 공통 한계가 아니다. 최대 크기는 Windows 버전과 클러스터 크기에 따라 다르며, Windows 10 버전 1709 이후 NTFS는 최대 8PB 볼륨을 지원한다.

[사용자 전환]
현재 사용자가 로그오프하지 않고 다른 사용자 계정으로 로그인하는 기능이다. 기존 사용자의 실행 중인 프로그램은 유지된다.
Win+L로 잠금 화면으로 이동한 뒤 다른 사용자로 로그인할 수 있다.

[창 관리 기능과 단축키]
- 에어로 스냅(Aero Snap): 창을 화면 가장자리로 끌어 크기와 위치를 맞춘다.
  Win+←/→ → 왼쪽·오른쪽 절반에 배치 / Win+↑ → 최대화 / Win+↓ → 복원 또는 최소화.
- 에어로 셰이크(Aero Shake): 창의 제목 표시줄을 흔들면 나머지 창이 최소화되고, 다시 흔들면 복원된다. 단축키: Win+Home.
- 에어로 피크(Aero Peek): 창을 최소화하지 않고 바탕화면을 잠깐 미리 본다. 단축키: Win+쉼표(,).
  피크 설정을 켜면 작업 표시줄 맨 오른쪽의 '바탕 화면 표시' 영역에 마우스를 올려 미리 볼 수 있다. 클릭하면 바탕화면이 표시된다.
  작업 표시줄의 실행 중인 앱 아이콘에 마우스를 올리면 열린 창의 미리 보기도 볼 수 있다.

[시험 핵심 암기]
GUI → 창·아이콘·마우스 / 선점형 → OS가 CPU 사용 제어
PnP → 자동 인식 / hdwwiz → 하드웨어 추가 / 핫 스왑 → 전원 켠 채 연결·분리
OLE 연결 → 원본 변경 반영 / 포함 → 원본과 독립
NTFS → 대용량·접근 권한·압축·암호화·자동 복구 / 사용자 전환 → 로그오프 불필요
스냅 → 창 배치 / 셰이크 → 나머지 창 최소화(Win+Home) / 피크 → 미리 보기(Win+,)

[확인 자료: Microsoft 공식 문서]
NTFS: https://learn.microsoft.com/en-us/windows-server/storage/file-server/ntfs-overview
단축키: https://support.microsoft.com/en-us/accessibility/windows/keyboard-shortcuts-in-windows

03. 라이브러리(Library)

여러 위치에 흩어진 폴더의 자료를 한곳에서 보고 정리할 수 있게 하는 가상의 폴더이다. 원본 파일을 옮기거나 복사하지 않고 모아서 보여 준다.
예: C드라이브와 D드라이브의 사진 폴더를 '사진' 라이브러리에서 함께 본다.

[주요 특징]
- 기본 라이브러리: 문서·음악·사진·비디오.
- 하나의 라이브러리에 최대 50개의 폴더를 포함할 수 있다.
- 라이브러리 자체를 삭제하거나, 포함된 폴더를 '라이브러리에서 제거'해도 원본 폴더·파일은 삭제되지 않는다.
- 라이브러리에서 실제 파일이나 하위 폴더를 '삭제'하면 원본도 삭제된다.
- 기본 라이브러리 복원: 파일 탐색기의 '라이브러리'에서 마우스 오른쪽 버튼 → 기본 라이브러리 복원.
- CD·DVD 같은 이동식 미디어는 포함할 수 없다. USB 저장장치도 무조건 가능한 것은 아니며, 고정식 드라이브로 인식되는 등 지원 조건을 충족해야 한다.

[시험 핵심 암기]
라이브러리 → 가상 폴더·여러 위치의 자료 통합·원본 위치 유지·최대 50개 폴더
라이브러리에서 제거 → 원본 유지 / 실제 파일 삭제 → 원본 삭제
기본 종류 → 문서·음악·사진·비디오

04. 가상 데스크톱

한 대의 컴퓨터에서 바탕화면 작업 공간을 여러 개 만들어, 용도별로 창을 나누어 사용하는 기능이다.
예: 데스크톱 1에는 공부 자료를, 데스크톱 2에는 업무 프로그램을 배치한다.
※ Windows를 여러 개 설치하는 것이 아니라, 같은 Windows 안에서 작업 공간을 나누는 것이다.

[주요 단축키: Win은 Windows 로고 키]
- Win+Tab: 작업 보기 실행. 열린 창과 가상 데스크톱을 확인한다.
- Win+Ctrl+D: 새 가상 데스크톱을 만들고 이동한다.
- Win+Ctrl+F4: 현재 가상 데스크톱을 닫는다.
- Win+Ctrl+→: 다음(오른쪽) 가상 데스크톱으로 이동한다.
- Win+Ctrl+←: 이전(왼쪽) 가상 데스크톱으로 이동한다.
※ 가상 데스크톱을 닫아도 실행 중인 앱은 종료되지 않고, 남아 있는 데스크톱으로 이동한다.

[시험 핵심 암기]
가상 데스크톱 → 한 컴퓨터·여러 작업 공간
Win+Tab → 작업 보기 / Win+Ctrl+D → 추가 / Win+Ctrl+F4 → 닫기
Win+Ctrl+좌우 방향키 → 데스크톱 전환

[확인 자료: Microsoft 공식 문서]
라이브러리: https://learn.microsoft.com/en-us/windows/client-management/client-tools/windows-libraries
가상 데스크톱: https://support.microsoft.com/en-gb/windows/experience/how-to-multitask-in-windows

05. Windows의 주요 바로가기 키

바로가기 키는 키보드로 명령을 빠르게 실행하는 방법이다. '+'는 키를 함께 누른다는 뜻이며, 일부 기능은 프로그램에 따라 다를 수 있다.

[기능 키]
- F1: 도움말을 연다.
- F2: 선택한 파일·폴더의 이름을 바꾼다.
- F3: 파일·폴더 등을 검색한다.
- F5: 현재 창을 새로 고친다. Ctrl+R도 새로 고침에 사용한다.

[선택과 편집]
- Ctrl+A: 전체 선택.
- Ctrl+C 또는 Ctrl+Insert: 복사. 원본을 유지한 채 복사본을 만든다.
- Ctrl+X: 잘라내기. 붙여넣기와 함께 사용하여 항목을 이동한다.
- Ctrl+V 또는 Shift+Insert: 복사하거나 잘라낸 내용을 붙여넣는다.

[화면 캡처]
- Print Screen(PrtSc): 화면 전체를 캡처한다.
- Alt+Print Screen: 현재 활성 창만 캡처한다.
※ 기본 동작에서는 캡처한 화면이 클립보드에 저장된다. 그림판 등에 Ctrl+V로 붙여넣은 뒤 파일로 저장할 수 있다.

[속성과 창 전환]
- Alt+Enter: 선택한 파일·폴더의 속성(등록 정보)을 표시한다.
- Alt+Esc: 창을 연 순서대로 전환한다.

[시험 핵심 암기]
F1 → 도움말 / F2 → 이름 변경 / F3 → 검색 / F5·Ctrl+R → 새로 고침
Ctrl+A → 전체 선택 / C → 복사 / X → 잘라내기 / V → 붙여넣기
Ctrl+Insert → 복사 / Shift+Insert → 붙여넣기
PrtSc → 전체 화면 / Alt+PrtSc → 활성 창 / Alt+Enter → 속성 / Alt+Esc → 창 전환

06. Windows의 주요 바로가기 키(추가)

[화면 캡처와 바탕화면]
- Win+PrtSc: 전체 화면을 캡처하여 '사진\스크린샷(Screenshots)' 폴더에 자동 저장한다.
- Win+Shift+S: 캡처 도구를 연다. 사각형·자유형·창·전체 화면 중 캡처 방식을 선택하며, 결과는 클립보드에 복사된다.
- Win+D: 바탕화면 표시. 다시 누르면 기존 창을 복원한다.
※ PrtSc → 클립보드에 복사 / Win+PrtSc → 파일로 자동 저장.

[Windows 기능 실행]
- Win+E: 파일 탐색기 실행.
- Win+L: PC 잠금. 잠금 화면에서 다른 사용자로 전환할 수 있다.
- Win+R: 실행 창 열기.
- Win+U: 접근성 설정 열기.
- Win+V: 클립보드 기록 표시. 기록 기능을 켜야 이전에 복사한 항목을 볼 수 있다.
- Ctrl+Esc: 시작 메뉴 표시.
- Win+X: 빠른 연결 메뉴 표시. 여기에서 PowerShell·장치 관리자 등의 관리 도구를 선택한다.
※ Win+X가 PowerShell을 곧바로 실행하는 것은 아니다. 메뉴 항목은 설정에 따라 다를 수 있다.

[창 전환과 종료]
- Alt+Tab: 열린 창의 목록을 보면서 사용할 창을 선택한다.
- Win+Tab: 작업 보기 실행. 열린 창과 가상 데스크톱을 확인한다.
- Win+T: 작업 표시줄의 앱을 차례로 선택한다. Enter를 누르면 선택한 앱을 연다.
- Alt+F4: 활성 창을 닫거나 프로그램을 종료한다.
- Ctrl+F4: 현재 문서를 닫는다. 여러 문서를 여는 프로그램에서 사용한다.
- Alt+Space: 활성 창의 시스템 메뉴를 연다. 이동·크기 조절·최소화·최대화·닫기 등을 선택한다.

[파일 탐색기와 편집]
- Ctrl+D 또는 Delete: 선택한 파일·폴더를 삭제한다. 일반적인 로컬 디스크에서는 휴지통으로 이동한다.
- Shift+Delete: 휴지통을 거치지 않고 삭제한다.
- Alt+P: 미리 보기 창 표시/숨기기.
- Alt+Shift+P: 세부 정보 창 표시/숨기기.
- Ctrl+마우스 휠: 파일·폴더 아이콘의 크기와 보기 형태 변경.
- Shift+F10: 선택한 항목의 바로 가기 메뉴 표시. 마우스 오른쪽 버튼과 같은 역할이다.
- Ctrl+Z: 실행 취소 / Ctrl+Y: 다시 실행. 지원 여부는 프로그램에 따라 다르다.
- CD를 넣을 때 Shift를 누르고 있기: CD 자동 실행을 일시적으로 막는다.

[돋보기]
- Win+더하기(+): 돋보기 실행·화면 확대.
- Win+빼기(-): 돋보기 화면 축소.
- Win+Esc: 돋보기 종료.

[작업 관리자: 시험에서 구분]
- Ctrl+Shift+Esc: 작업 관리자를 바로 실행한다.
- Ctrl+Alt+Delete: Windows 보안 화면을 표시한다. 여기에서 작업 관리자·잠금·로그아웃 등을 선택한다.
