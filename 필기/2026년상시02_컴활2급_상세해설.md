## 제1과목 컴퓨터 일반

### 1. AR/VR 핵심 기술 - 정답 ② 스트리밍(Streaming)

AR·VR의 핵심 기술은 사용자의 동작을 감지하고, 가상 세계를 만들며, 그 안에서 상호작용하게 하는 기술입니다. **스트리밍**은 멀티미디어 데이터를 내려받는 동시에 재생하는 전송 기술이므로 AR·VR만의 핵심 구성 기술로 보지 않습니다.

- **인터랙션(Interaction):** 사용자의 입력이나 행동에 가상 환경이 반응하게 합니다.
- **렌더링(Rendering):** 모델·조명·재질 등을 계산하여 가상 장면을 영상으로 만듭니다.
- **트래킹(Tracking):** 머리, 손, 몸 또는 기기의 위치와 움직임을 추적합니다.
- **스트리밍:** 오디오·비디오 등을 실시간으로 전송·재생하는 기술로, AR·VR 서비스에 활용될 수는 있지만 핵심 구현 기술 자체는 아닙니다.

**암기 포인트:** AR·VR = 상호작용 + 렌더링 + 움직임 추적.

### 2. 네트워크 장비 - 정답 ③

③은 **브리지(Bridge)**가 아니라 **리피터(Repeater)**에 대한 설명입니다. 리피터는 전송 중 약해지거나 왜곡된 신호를 재생·증폭하여 전달 거리를 늘립니다.

- **라우터:** 패킷의 목적지 주소를 보고 최적 경로를 선택하여 서로 다른 네트워크를 연결합니다.
- **허브:** 여러 컴퓨터를 한곳에 연결하는 집중화 장치입니다. 수신한 신호를 연결된 포트로 전달합니다.
- **브리지:** 같은 종류의 LAN 구간을 연결하고 MAC 주소를 기준으로 필요한 프레임만 전달하여 트래픽을 줄입니다.
- **게이트웨이:** 프로토콜이나 구조가 서로 다른 네트워크 사이에서 변환·연결 역할을 합니다.

**구분:** 리피터 = 신호 재생, 브리지 = LAN 분할·연결, 라우터 = 경로 선택, 게이트웨이 = 서로 다른 망의 변환.

### 3. 소프트웨어 테스트 - 정답 ① 알파 테스트

개발자의 장소에서 선정된 사용자가 개발자 앞에서 시험하고, 통제된 환경에서 사용자와 개발자가 함께 문제점을 확인하는 방식은 **알파 테스트(Alpha Test)**입니다.

- **알파 테스트:** 개발사 내부 또는 개발자의 통제된 환경에서 실제 사용자를 참여시켜 수행합니다.
- **베타 테스트:** 개발이 거의 끝난 제품을 제한된 외부 사용자에게 배포하여 실제 사용 환경에서 시험합니다.
- **벤치마크 테스트:** 여러 제품이나 시스템의 성능을 동일한 기준으로 측정·비교합니다.
- **데모 테스트:** 제품 기능을 시연하거나 제한적으로 체험하게 하는 의미에 가깝습니다.

**암기 포인트:** 알파 = 개발사 안, 베타 = 사용자 환경.

### 4. Windows 10 인쇄 기능 - 정답 ②

프린터의 속성 창에서는 용지 종류, 공유 여부, 사용할 포트와 같은 항목을 설정할 수 있으므로 ②가 옳습니다.

- ① 기본 프린터는 여러 대를 동시에 지정할 수 없고 **한 대만** 지정합니다.
- ③ 인쇄 대기 중인 작업도 인쇄 대기열에서 취소할 수 있습니다.
- ④ 인쇄 중인 작업도 일시 중지하거나 취소할 수 있습니다.

**정리:** 여러 프린터를 설치할 수는 있지만 기본 프린터는 하나이며, 대기 중이거나 인쇄 중인 문서 모두 관리할 수 있습니다.

### 5. 인터넷 - 정답 ②

인터넷은 TCP/IP를 기반으로 전 세계의 수많은 컴퓨터와 네트워크가 연결된 **비영리·개방형 분산 네트워크**입니다. 특정 중앙 통제 기구가 전체 인터넷을 운영하지 않으므로, 인터넷을 상업용 네트워크라고 하고 InterNIC이 중앙에서 운영한다고 한 ②가 틀렸습니다.

- **URL:** 인터넷 자원의 위치를 나타내는 표준 주소 체계입니다.
- **IP 주소:** 인터넷에 연결된 장치를 구분하기 위한 논리적 주소입니다.
- **WWW:** 웹 브라우저와 하이퍼텍스트를 이용해 인터넷의 정보를 효과적으로 이용하게 하는 서비스입니다.

**주의:** 인터넷은 기반 통신망이고, WWW는 인터넷에서 사용하는 여러 서비스 중 하나입니다.

### 6. Windows 10 작업 표시줄 - 정답 ②

아이콘의 보기 형식과 정렬 방식은 **바탕 화면의 바로 가기 메뉴**에서 지정합니다. 작업 표시줄에서 하는 작업이 아니므로 ②가 옳지 않습니다.

- 같은 종류의 작업 표시줄 단추를 하나로 묶어 표시할 수 있습니다.
- 작업 표시줄을 잠가 크기나 위치가 뜻하지 않게 변경되지 않도록 할 수 있습니다.
- 작업 표시줄 자동 숨기기를 설정할 수 있습니다.

**구분:** 아이콘 크기·자동 정렬 = 바탕 화면, 단추 묶기·잠금·자동 숨기기 = 작업 표시줄.

### 7. 소프트웨어 배포 버전 - 정답 ①

①의 설명은 **번들 버전(Bundle Version)**입니다. 트라이얼 버전은 제품을 사기 전에 일정 기간 또는 제한된 기능으로 사용해 보게 하는 시험판입니다.

- **번들 버전:** 하드웨어나 다른 소프트웨어를 구매할 때 함께 제공됩니다.
- **트라이얼 버전:** 사용 기간이나 일부 기능을 제한한 체험판입니다.
- **베타 버전:** 정식 발표 전에 오류를 찾고 사용성을 시험하려고 배포하는 시험판입니다.
- **데모 버전:** 제품 홍보를 위해 사용 기간이나 기능을 제한한 시연판입니다.
- **패치 버전:** 이미 배포된 프로그램의 오류를 수정하거나 성능을 개선하는 파일입니다.

### 8. 멀티미디어 인터페이스 - 정답 ① HDMI

영상 신호와 음향 신호를 압축하지 않고 하나의 케이블로 통합 전송하는 고선명 멀티미디어 인터페이스는 **HDMI(High-Definition Multimedia Interface)**입니다.

- HDMI는 디지털 영상과 다채널 음성을 함께 전송합니다.
- DVI는 주로 디지털 영상 전송에 사용되며 일반적으로 음성 통합 전송이 핵심이 아닙니다.
- USB는 범용 주변장치 연결 규격입니다.
- IEEE 1394는 고속 직렬 인터페이스로 디지털 캠코더 등에 사용되었습니다.

### 9. 작업 표시줄 점프 목록 - 정답 ④

점프 목록에서 항목을 제거할 때는 해당 항목의 바로 가기 메뉴에서 **[이 목록에서 제거]**를 선택합니다. 항목을 가리킨 뒤 `Delete` 키를 누르는 방식이 아니므로 ④가 틀렸습니다.

- 작업 표시줄의 앱 아이콘을 마우스 오른쪽 단추로 누르면 점프 목록을 볼 수 있습니다.
- 목록의 항목을 클릭하면 해당 문서나 위치를 바로 열 수 있습니다.
- 압정 아이콘으로 자주 쓰는 항목을 점프 목록에 고정할 수 있습니다.

### 10. 정보 보안 위협 - 정답 ④ 키로거

키보드로 입력하는 내용을 몰래 기록하여 아이디, 비밀번호와 같은 개인정보를 빼내는 프로그램은 **키로거(Key Logger)**입니다.

- **스니핑(Sniffing):** 네트워크를 오가는 패킷을 도청·분석하는 행위입니다. ①은 계정과 패스워드로 접속을 시도하는 스푸핑 계열 설명에 가깝습니다.
- **피싱(Phishing):** 가짜 웹 사이트나 이메일로 사용자를 속여 금융정보 등을 직접 입력하게 합니다. ②처럼 몰래 프로그램을 설치해 정보를 수집하는 설명은 스파이웨어에 가깝습니다.
- **스푸핑(Spoofing):** IP, DNS, 이메일 발신자 등의 정보를 속여 다른 주체인 것처럼 위장합니다. ③의 악성코드인 것처럼 거짓 경고하는 행위는 혹스(Hoax)입니다.
- **키로거:** 키 입력을 가로채 기록합니다.

### 11. Windows 10 검색 상자 - 정답 ④

`Win + F`는 검색 상자에 포커스를 옮기는 키가 아니라 **피드백 허브**를 실행하는 바로 가기 키입니다. Windows 검색은 일반적으로 `Win + S`를 사용합니다.

- 검색 범주로 모두, 앱, 문서, 웹, 동영상, 설정, 전자 메일, 폴더 등을 사용할 수 있습니다.
- 작업 표시줄 설정에서 검색 상자를 표시하거나 숨길 수 있습니다.
- 검색 결과에서 앱을 바로 실행할 수 있습니다.

### 12. 가상 현실(VR) - 정답 ②

가상 현실은 고도의 컴퓨터 그래픽과 3차원 기술로 만든 가상 세계에서 사용자가 실제와 비슷한 경험을 하게 하는 기술입니다.

- ①은 고화질 영상 제작·방송에 관한 설명입니다.
- ③은 2차원 그래픽 표현입니다.
- ④는 복잡한 데이터를 단순한 화면으로 나타내는 데이터 시각화에 가깝습니다.

**핵심:** VR은 단순한 3차원 그림이 아니라 몰입과 상호작용을 통해 가상 환경을 체험하게 합니다.

### 13. 벡터 그래픽 - 정답 ①

벡터 방식은 점과 점을 연결하는 직선·곡선의 위치와 수학적 정보를 이용해 이미지를 표현합니다.

- 확대해도 수학적으로 다시 계산하므로 계단 현상이 거의 없고 선명합니다.
- 사진처럼 복잡하고 미세한 색 변화 표현에는 비트맵이 더 적합합니다.
- 화면 표시 속도가 빠르다고 일률적으로 말할 수 없으며, 복잡한 도형은 계산이 필요합니다.
- 많은 픽셀과 다양한 색으로 표현한다는 설명은 비트맵 방식입니다.

**구분:** 벡터 = 도형·선·수식, 비트맵 = 픽셀·사진.

### 14. 주기억장치 - 정답 ①

①은 주기억장치가 아니라 **보조기억장치**의 설명입니다. 대용량 데이터와 프로그램을 비휘발성으로 장기간 보관하는 장치는 HDD, SSD 같은 보조기억장치입니다.

- 주기억장치에는 RAM과 ROM이 있습니다.
- ROM에는 BIOS, 부팅에 필요한 프로그램, POST 등이 저장될 수 있습니다.
- 주기억장치는 CPU가 직접 접근할 수 있고 현재 실행 중인 프로그램과 데이터를 둡니다.
- RAM은 구조에 따라 DRAM과 SRAM으로 구분합니다.

**비교:** 주기억장치 = CPU가 직접 접근, 보조기억장치 = 대용량 장기 저장.

### 15. WWW - 정답 ④

④는 HTML이 아니라 **HTTP**에 관한 설명입니다. HTML은 웹 페이지의 구조와 내용을 작성하는 하이퍼텍스트 마크업 언어이고, HTTP는 웹 서버와 웹 브라우저 사이에서 웹 문서를 주고받는 통신 프로토콜입니다.

- WWW는 문자, 그림, 소리, 영상 등 멀티미디어 정보를 제공합니다.
- 웹 문서는 하이퍼텍스트로 연결됩니다.
- 서버는 정보를 제공하고 클라이언트의 웹 브라우저는 정보를 요청·표시합니다.

**암기 포인트:** HTML = 문서 작성, HTTP = 문서 전송.

### 16. 인터넷 홈페이지 제작 언어 - 정답 ④ AIDA

AIDA는 CPU, 메인보드, 메모리, 그래픽 카드 등 PC의 하드웨어 정보를 확인하는 유틸리티 프로그램이지 홈페이지 제작 언어가 아닙니다.

- **DHTML:** HTML, CSS, 스크립트 등을 결합해 동적인 웹 페이지를 구현합니다.
- **ASP:** 서버 측에서 동적인 웹 페이지를 만드는 기술입니다.
- **JAVA:** 네트워크 환경에서 실행 가능한 객체지향 언어이며 웹 응용 프로그램 제작에도 사용됩니다.

### 17. 컴퓨터 범죄 예방 - 정답 ②

의심스러운 이메일은 내용을 확인하려고 열어보면 안 됩니다. 첨부 파일이나 링크에 악성코드·피싱 요소가 있을 수 있으므로 열지 말고 삭제하거나 신고해야 합니다.

- 정기적인 해킹·취약점 점검은 예방에 도움이 됩니다.
- 백신 프로그램 설치와 자동 업데이트는 최신 악성코드 대응에 필요합니다.
- 사이트마다 강하고 서로 다른 비밀번호를 사용하고 주기적으로 관리해야 합니다.

### 18. Windows 10 프린터 설치 - 정답 ③

네트워크 검색으로 프린터를 선택하면 연결에 필요한 포트가 일반적으로 자동으로 지정됩니다. 사용자가 반드시 포트를 직접 지정한다고 한 ③이 틀렸습니다.

- [설정] → [장치] → [프린터 및 스캐너]에서 프린터를 추가할 수 있습니다.
- 로컬, Bluetooth, 무선, 네트워크 검색 프린터 등을 선택할 수 있습니다.
- 여러 프린터 중 하나를 기본 프린터로 지정할 수 있습니다.

### 19. 문자 데이터 표현 코드 - 정답 ④ Hamming Code

해밍 코드(Hamming Code)는 문자 표현 코드가 아니라 데이터 전송·저장 중 발생한 오류를 검출하고 교정하기 위한 오류 제어 코드입니다.

- **ASCII:** 영문자, 숫자, 기호 등을 표현하는 7비트 문자 코드입니다.
- **EBCDIC:** IBM 계열 대형 컴퓨터에서 사용한 8비트 문자 코드입니다.
- **Unicode:** 세계 여러 언어의 문자를 통일해 표현하는 국제 문자 코드 체계입니다.

### 20. ASCII 코드 - 정답 ③

표준 ASCII는 7비트를 사용하여 영문 대·소문자, 숫자, 문장 부호, 특수 기호, 제어 문자 등을 표현합니다.

- ① ASCII 자체에는 오류 검출·교정 기능이 없습니다.
- ② 표준 ASCII는 3개의 존 비트와 4개의 디지트 비트로 구성되지만, 대형 컴퓨터의 범용 코드라는 설명은 EBCDIC에 해당합니다.
- ④ 확장 ASCII는 8비트를 사용하지만 멀티미디어 데이터 표현에 적합하도록 만든 코드는 아닙니다.

**암기 포인트:** 표준 ASCII = 7비트, 최대 128가지 문자.

## 제2과목 스프레드시트 일반

### 21. 데이터 통합 - 정답 ②

원본 데이터와 통합 결과가 같은 통합 문서 안에 있을 때만 **[원본 데이터에 연결]**을 사용할 수 있다는 설명은 틀렸습니다. 다른 통합 문서의 범위도 원본으로 지정하고 연결하여 통합 결과를 갱신할 수 있습니다.

- 데이터는 위치를 기준으로 통합하거나, 레이블 이름을 기준으로 범주별 통합할 수 있습니다.
- 여러 원본 범위의 레이블이 정확히 일치하지 않으면 별도의 행이나 열로 처리될 수 있습니다.
- 여러 시트나 다른 통합 문서에 있는 범위를 하나로 통합할 수 있습니다.

**구분:** 위치 기준 = 같은 셀 위치끼리, 범주 기준 = 같은 레이블끼리 통합.

### 22. 차트 종류 - 정답 ③ 거품형 차트

수량, 실적, 점유율처럼 서로 관련된 **세 개의 수치 데이터 계열**을 한 번에 표현하려면 거품형 차트가 가장 적절합니다.

- 가로축 값: 수량
- 세로축 값: 실적
- 거품의 크기: 점유율

거품형 차트는 분산형 차트에 세 번째 변수의 크기 정보를 추가한 형태입니다. 도넛형·가로 막대형·영역형은 세 변수의 관계를 이 방식으로 동시에 나타내기 어렵습니다.

### 23. 피벗 테이블 작성 - 정답 ①

그림의 피벗 테이블이 시작하는 왼쪽 위 셀은 **M5**입니다. M3은 보고서 필터가 놓인 위치일 뿐이므로, 피벗 테이블을 삽입할 위치로 M3을 선택했다는 ①이 틀렸습니다.

- `직업`은 위쪽의 보고서 필터 영역에 배치되어 있습니다.
- 보험 종류는 열 레이블 영역에 있습니다.
- 그림에는 행 방향의 전체 합계만 나타나므로 열의 총합계만 표시하도록 설정한 형태입니다.
- 1월, 2월, 3월로 묶인 항목은 행 영역의 날짜 필드를 월 단위로 그룹화한 것입니다.

### 24. 목표값 찾기 - 정답 ③

상품 가격은 이미 2,500원으로 정해져 있고 총 판매액을 1,500,000원으로 만들기 위해 판매 수량 하나를 역산하려는 상황이므로 **목표값 찾기**가 적합합니다.

- 목표 셀: 총 판매액 수식이 있는 셀
- 목표값: 1,500,000
- 값을 바꿀 셀: 판매 수량 셀

피벗 테이블은 요약, 고급 필터는 조건 추출, 시나리오는 여러 입력값 조합의 결과 비교에 사용합니다.

### 25. 수식 오류 메시지 - 정답 ④

`#REF!`는 수식이 참조하던 셀이나 범위가 삭제되는 등 **셀 참조가 유효하지 않을 때** 나타납니다. 인수가 필요한 함수에 다른 인수를 지정한 경우라는 ④의 설명은 맞지 않습니다.

- `#VALUE!`: 잘못된 인수·피연산자 또는 잘못된 자료형을 사용했습니다.
- `#DIV/0!`: 0이나 빈 셀로 나누었습니다.
- `#NAME?`: 함수명이나 정의된 이름을 잘못 입력했거나 텍스트 표기를 인식하지 못했습니다.
- `#REF!`: 유효하지 않은 셀 참조입니다.

### 26. 사용자 지정 표시 형식 - 정답 ④

`#`은 유효한 숫자만 표시하는 선택적 자릿수 기호입니다. 입력값 12에 `#.#` 형식을 지정해도 불필요한 소수 0은 표시하지 않으므로 결과는 `12`입니다. `12.0`이라고 한 ④가 틀렸습니다.

- `[>5]"▲";"▼"`에서 2는 조건을 만족하지 않으므로 `▼`가 표시됩니다.
- `@ "판매량"`은 입력된 텍스트 뒤에 `판매량`을 붙이므로 `5월 판매량`이 됩니다.
- `?/?`는 수를 분수로 표시하므로 1.25는 `5/4`로 표시됩니다.

**표시 형식 기호:** `0`은 의미 없는 0도 표시, `#`은 유효 숫자만 표시, `?`는 자릿수를 맞추기 위한 공백을 확보합니다.

### 27. 매크로 기록 - 정답 ②

매크로 이름에는 공백을 사용할 수 없습니다. 첫 글자는 문자여야 하고, 이후에는 문자·숫자·밑줄을 사용할 수 있습니다. 따라서 공백과 밑줄을 모두 사용할 수 있다고 한 ②가 틀렸습니다. 셀 주소와 혼동되는 이름도 사용할 수 없습니다.

- 바로 가기 키는 `Ctrl`과 영문자를 조합하며 숫자나 특수문자를 사용할 수 없습니다.
- 매크로가 들어 있는 통합 문서가 열려 있는 동안 기존 Excel 바로 가기 키와 겹치면 매크로 바로 가기 키가 우선할 수 있습니다.
- 대문자를 지정하면 실제 실행 키는 `Ctrl + Shift + 해당 문자`가 됩니다.

### 28. 시트 보호 - 정답 ②

새 워크시트의 모든 셀에는 기본적으로 **잠금** 속성이 설정되어 있습니다. 잠긴 셀을 보호하려면 잠금을 해제하는 것이 아니라 잠금 상태를 유지한 채 **시트 보호를 실행**해야 합니다. 따라서 ②가 틀렸습니다.

- 셀의 잠금·숨김 속성은 시트를 보호하기 전에는 실제 제한 효과가 없습니다.
- 시트 보호 후 잠긴 셀을 수정하려 하면 경고 메시지가 나타납니다.
- 수식을 숨기려면 셀의 `숨김` 속성을 설정한 뒤 시트를 보호합니다.

**핵심:** 셀 서식의 잠금·숨김 설정 + 시트 보호 실행 = 실제 보호 적용.

### 29. 틀 고정 및 창 나누기 - 정답 ③

창 나누기 구분선을 제거할 때는 [보기] → [창] → **[나누기]를 다시 선택**하거나, 나누기 선을 창 가장자리로 끌거나 더블클릭합니다. [숨기기]를 선택한다는 ③이 틀렸습니다.

- 셀 포인터 위치에 따라 수직, 수평 또는 수직·수평 방향으로 창을 나눌 수 있습니다.
- 화면의 창 나누기 상태는 인쇄 결과에 적용되지 않습니다.
- 첫 행 고정은 셀 포인터 위치와 관계없이 [틀 고정] → [첫 행 고정]으로 실행합니다.

### 30. 함수 결과 비교 - 정답 ③

③만 결과가 `123.66`이고 나머지는 모두 `123.65`입니다.

- `=LEFT(123.654, 6)` → 숫자를 텍스트 `123.654`로 보고 왼쪽 6글자인 `123.65` 반환
- `=ROUND(123.654, 2)` → 소수 셋째 자리 4를 반올림하여 `123.65`
- `=ROUNDUP(123.654, 2)` → 소수 셋째 자리 이하가 있으므로 올림하여 `123.66`
- `=ROUNDDOWN(123.654, 2)` → 소수 셋째 자리 이하를 버려 `123.65`

**함수 구분:** ROUND = 반올림, ROUNDUP = 0에서 멀어지게 올림, ROUNDDOWN = 0에 가까워지게 내림.

### 31. 고급 필터 - 정답 ② (3행, 5행)

고급 필터의 조건 범위에서 **같은 행의 조건은 AND**, **서로 다른 행의 조건은 OR**로 연결합니다.

- 조건 1: `직책=대리 AND 경력>=4` → 3행 김상공
- 조건 2: `TOEIC>=500 AND TOEIC<700` → 5행 박대한
- 두 조건 행은 OR 관계이므로 최종 추출 결과는 3행과 5행입니다.

같은 필드에 두 조건을 동시에 걸려면 그림처럼 `TOEIC` 필드명을 두 열에 반복하고 같은 행에 조건을 적습니다.

### 32. 페이지 설정의 머리글/바닥글 탭 - 정답 ③

워크시트를 실제 크기의 백분율로 확대·축소하거나 한 페이지 너비·높이에 맞추는 기능은 **[페이지] 탭**에서 설정합니다. [머리글/바닥글] 탭의 기능이 아니므로 ③이 틀렸습니다.

- `짝수와 홀수 페이지를 다르게 지정`하여 홀수·짝수 머리글을 따로 만들 수 있습니다.
- `첫 페이지를 다르게 지정`한 뒤 첫 페이지 머리글·바닥글을 비워 두면 첫 페이지에 표시하지 않을 수 있습니다.
- `페이지 여백에 맞추기`는 머리글·바닥글 위치를 페이지 여백과 맞춥니다.

### 33. RANK.EQ 함수 - 정답 ④

경기 기록은 시간이 짧을수록 높은 순위이므로 오름차순 순위를 사용해야 합니다. C2에 입력할 수식은 다음과 같습니다.

```excel
=RANK.EQ(B2, $B$2:$B$5, 1)
```

- `B2`: 순위를 구할 홍길동의 기록
- `$B$2:$B$5`: 비교할 전체 기록 범위. 아래로 복사해도 변하지 않도록 절대 참조합니다.
- `1`: 오름차순 순위. 가장 작은 값이 1위입니다.

세 번째 인수가 0이거나 생략되면 내림차순으로 큰 값이 1위가 됩니다.

### 34. 채우기 핸들 - 정답 ①

문자와 숫자가 혼합된 셀을 채우기 핸들로 끌면 숫자 부분이 연속 데이터로 증가할 수 있습니다. 이때 `Ctrl`을 누른 채 끌면 같은 내용을 복사하므로 ①이 옳습니다.

- 숫자 두 개를 선택해 끌면 두 값의 차이를 간격으로 하는 등차수열이 만들어집니다. 두 번째 값만 반복되지 않습니다.
- 숫자 하나를 `Ctrl`과 함께 끌면 숫자가 1씩 증가합니다. 감소하는 것이 아닙니다.
- 사용자 지정 목록은 첫 항목을 입력하고 일반적으로 `Ctrl` 없이 끌어야 목록 순서대로 채워집니다. `Ctrl`을 누르면 같은 값 복사로 바뀔 수 있습니다.

### 35. 시나리오 추가 - 정답 ④

시트가 보호된 상태에서 시나리오가 표시되지 않게 하려면 **[숨기기]**를 선택해야 합니다. `변경 금지`는 시나리오의 변경을 막는 옵션이지 표시 여부를 결정하는 옵션이 아니므로 ④가 틀렸습니다.

- [데이터] → [예측] → [가상 분석] → [시나리오 관리자]에서 [추가]를 선택합니다.
- 변경할 셀을 먼저 선택하면 시나리오 추가 대화상자에 셀 주소가 자동으로 들어갑니다.
- 설명은 선택 사항이므로 반드시 입력할 필요가 없습니다.
- `변경 금지`와 `숨기기`는 시트가 보호될 때 효력이 있습니다.

### 36. 이름 정의 - 정답 ③

이 문제는 **통합 문서 범위로 정의한 이름**을 전제로 합니다. 이 경우 시트가 달라도 같은 이름을 중복 사용할 수 없으므로 ③이 틀린 설명입니다.

- 이름의 첫 문자는 문자, 밑줄(`_`), 역슬래시(`\`)로 시작할 수 있습니다.
- 이름에는 공백을 사용할 수 없습니다.
- 영문 대문자와 소문자를 구분하지 않습니다.
- 셀 주소와 혼동되는 이름은 사용할 수 없습니다.

**시험 포인트:** 이름은 수식의 셀·범위 참조를 읽기 쉽게 만드는 별칭이며, 공백과 셀 주소 형태는 허용되지 않습니다.

> **실제 Excel의 예외:** 이름을 통합 문서가 아닌 특정 워크시트 범위로 정의하면 다른 시트에서 같은 로컬 이름을 만들 수 있습니다. 다만 이 문항과 공식 답안은 일반적인 통합 문서 범위 이름을 묻는 것으로 처리합니다.

### 37. 현재 연도 구하기 - 정답 ③

`TODAY()`는 시스템의 현재 날짜를 반환하고, `YEAR()`는 날짜에서 연도만 추출합니다. 따라서 정답은 다음 수식입니다.

```excel
=YEAR(TODAY())
```

- `DAY()`는 날짜에서 일을 구합니다.
- `DAYS()`는 두 날짜 사이의 일수를 계산합니다.
- `DATE()`는 연·월·일을 인수로 받아 날짜를 만듭니다.

### 38. 행/열 숨기기 - 정답 ①

숨겨진 행이나 열이 포함되도록 범위를 선택한 뒤 행 높이 또는 열 너비를 다시 지정하면 숨김이 해제되어 화면에 표시됩니다. 따라서 계속 표시되지 않는다고 한 ①이 틀렸습니다.

- 이름 상자에 숨겨진 셀 주소를 입력해 해당 셀을 선택한 뒤 [홈] → [셀] → [서식] → [숨기기 및 숨기기 취소]에서 해제할 수 있습니다.
- 숨겨진 행이나 열은 인쇄되지 않습니다.
- 숨겨진 행·열은 정렬 과정에서 일반 표시 행·열처럼 위치가 이동하지 않습니다.

### 39. 매크로 - 정답 ①

같은 통합 문서 안에서는 시트가 다르더라도 동일한 이름의 매크로를 중복해서 기록할 수 없습니다. 따라서 ①이 틀렸습니다.

- 매크로 바로 가기 키에 영문 대문자를 지정하면 `Shift`가 자동으로 포함되어 `Ctrl + Shift + 문자`로 실행됩니다.
- 어느 통합 문서에서도 사용하려면 저장 위치를 `개인용 매크로 통합 문서`로 선택합니다.
- 매크로 보안 설정으로 매크로 실행 허용 수준과 알림 방식을 제어할 수 있습니다.

### 40. 여러 데이터 계열을 표현하는 원형 계열 차트 - 정답 ② 도넛형 차트

도넛형 차트는 원형 차트를 개선한 형태로, 여러 개의 데이터 계열을 동심원 형태의 여러 고리로 표시할 수 있습니다.

- **원형 차트:** 전체에 대한 각 항목의 비율을 보여 주며 일반적으로 한 데이터 계열만 사용합니다.
- **3차원 효과의 원형 차트:** 원형 차트에 입체 효과를 준 것으로 여러 계열을 표현하는 차트는 아닙니다.
- **원뿔형 차트:** 세로 막대형 또는 가로 막대형 계열을 원뿔 모양으로 표현합니다.

**암기 포인트:** 원형 = 한 계열, 도넛형 = 여러 계열 가능.

## 마지막 정리 - 시험 직전 핵심 구분

- **리피터 / 브리지 / 라우터 / 게이트웨이:** 신호 재생 / LAN 구간 연결 / 경로 선택 / 서로 다른 망 변환
- **알파 / 베타 테스트:** 개발사 통제 환경 / 외부 사용자의 실제 환경
- **HTML / HTTP:** 웹 문서 작성 언어 / 웹 문서 전송 프로토콜
- **벡터 / 비트맵:** 선·도형을 수학식으로 표현 / 픽셀 단위로 표현
- **ASCII / EBCDIC / Unicode / Hamming:** 7비트 문자 / IBM 대형 컴퓨터 문자 / 국제 문자 체계 / 오류 검출·교정
- **0 / # / ?:** 빈 자리를 0으로 표시 / 유효 숫자만 표시 / 자릿수 정렬용 공백 확보
- **ROUND / ROUNDUP / ROUNDDOWN:** 반올림 / 올림 / 내림
- **고급 필터 조건:** 같은 행은 AND, 다른 행은 OR
- **RANK.EQ 세 번째 인수:** 0 또는 생략은 내림차순, 1은 오름차순
- **원형 / 도넛형:** 한 데이터 계열 / 여러 데이터 계열 가능
