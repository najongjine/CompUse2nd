1. Plug and Play 기능에 대해 올바르게 설명한 것은?

① 새로운 장치를 설정하면 자동적으로 감지하여 적절한 조치를 취하여 사용자가 쉽게 새로운 부품이나 주변 장치를 설치할 수 있도록 지원하는 기능이다.
② 새로운 장치를 설정한 후 수동적으로 Setting만 시켜주면 사용자가 쉽게 사용할 수 있도록 하는 기능이다.
③ 윈도우에서 여러 개의 작업을 동시에 수행할 수 있게 지원하는 기능이다.
④ 기존의 도스 시스템보다 수행 속도를 저해시키는 윈도우의 앱 수행 방식이다.

정답: ①
해설: Plug and Play(PnP)는 새 하드웨어를 연결했을 때 운영체제가 장치를 자동으로 인식하고 필요한 드라이버와 시스템 자원을 구성해 주는 기능이다. ②처럼 사용자가 반드시 수동으로 설정하는 기능이 아니며, ③은 다중 작업(멀티태스킹)에 관한 설명이고 ④는 PnP와 관계없는 설명이다.


2. 다음 중 한글 Windows 10에서 실행 중인 프로그램 사이의 작업 전환을 위한 바로 가기 키는?

① Alt + Enter
② Alt + F4
③ Alt + Tab
④ Alt + Delete

정답: ③ Alt + Tab
해설: Alt + Tab은 실행 중인 앱이나 창 사이를 전환한다. Alt + Enter는 선택 항목의 속성 표시 또는 일부 프로그램의 전체 화면 전환에 사용되고, Alt + F4는 현재 창이나 프로그램을 닫는다. Alt + Delete는 일반적인 작업 전환 단축키가 아니다.


3. 다음 중 Windows에서 Winkey(윈도우 키)와 함께 사용하는 바로 가기 키에 대한 설명으로 틀린 것은?

① 윈도우 키 + I : ‘설정’ 창을 표시함
② 윈도우 키 + D : 모든 창을 최소화함
③ 윈도우 키 + L : 컴퓨터를 잠금
④ 윈도우 키 + E : ‘실행’ 창을 표시함

정답: ④
해설: Windows 키 + E는 ‘파일 탐색기’를 실행한다. ‘실행’ 창을 여는 단축키는 Windows 키 + R이다. Windows 키 + I는 설정, Windows 키 + D는 바탕 화면 표시, Windows 키 + L은 PC 잠금 기능이므로 ①~③은 옳다.


4. 다음 중 Windows에서 바로 가기 아이콘에 대한 설명으로 옳지 않은 것은?

① 원본 파일이 있는 위치와 관계없이 만들 수 있다.
② 하나의 원본 파일에 대하여 여러 개의 바로 가기 아이콘을 만들 수 있다.
③ 바로 가기 아이콘의 확장자는 LNK이다.
④ 원본 파일을 삭제하면 바로 가기 아이콘을 실행할 수 없다.

정답: 정답 없음(문항 오류)
해설: ①~④가 모두 옳다. 바로 가기는 원본과 다른 위치에도 만들 수 있고, 하나의 원본에 여러 개를 만들 수도 있으며, 확장자는 .lnk이다. 원본이 삭제되거나 이동되어 경로가 끊기면 바로 가기로 실행할 수 없다. 따라서 ‘옳지 않은 것’을 고르는 현재 선택지에는 정답이 없다.


5. 다음 중 작업 표시줄의 바로 가기 메뉴에서 선택할 수 없는 항목은?

① 작업 표시줄에 피플 표시
② 터치 키보드 단추 표시
③ 작업 보기 단추 표시
④ 개인 설정 표시

정답: ④
해설: 작업 표시줄의 빈 곳을 마우스 오른쪽 단추로 클릭하면 피플 표시, 터치 키보드 단추 표시, 작업 보기 단추 표시 등을 선택할 수 있다. ‘개인 설정 표시’라는 항목은 없으며, 작업 표시줄의 모양과 동작은 ‘작업 표시줄 설정’에서 변경한다.


6. 다음 중 한글 Windows 10의 작업 표시줄 설정에 대한 설명으로 옳지 않은 것은?

① 자주 사용하는 앱을 작업 표시줄에 표시할 수 있다.
② 데스크톱 모드에서 작업 표시줄 자동 숨기기를 설정할 수 있다.
③ 화면에서 작업 표시줄의 위치를 왼쪽, 위쪽, 오른쪽, 아래쪽 중에서 설정할 수 있다.
④ 작업 표시줄이 꽉 차면 같은 앱은 그룹으로 묶어서 하나의 단추로 표시되도록 할 수 있다.

정답: ①
해설: ‘작업 표시줄 설정’에는 자주 사용하는 앱을 자동으로 표시하는 옵션이 없다. 원하는 앱은 직접 ‘작업 표시줄에 고정’해야 한다. 자동 숨기기, 작업 표시줄 위치, 단추 결합 방식은 작업 표시줄 설정에서 지정할 수 있으므로 ②~④는 옳다.


7. 하나의 컴퓨터에서 A 사용자가 여러 개의 프로그램을 실행시킨 상태에서 잠시 B 사용자가 사용할 수 있도록 하는 방법으로 옳은 것은?
(단, 해당 컴퓨터에 사용자 A와 사용자 B의 계정은 모두 등록되어 있다.)

① 로그오프를 수행한다.
② 사용자 전환을 수행한다.
③ 시스템을 다시 시작한다.
④ 전원을 종료한 후 재부팅한다.

정답: ②
해설: ‘사용자 전환’을 하면 A 사용자의 프로그램을 종료하지 않고 로그인 상태를 유지하면서 B 계정으로 로그인할 수 있다. 로그오프, 다시 시작, 종료를 하면 A 사용자의 실행 중인 프로그램이 종료되므로 조건에 맞지 않는다.


8. 다음 중 Windows 10 작업 표시줄의 점프 목록 사용에 대한 설명으로 옳지 않은 것은?

① 프로그램의 점프 목록을 보려면 작업 표시줄의 프로그램 아이콘을 마우스 오른쪽 단추로 클릭한다.
② 점프 목록에서 항목을 열려면 프로그램의 점프 목록에서 해당 항목을 클릭한다.
③ 점프 목록에 항목을 고정하려면 프로그램의 점프 목록에서 항목을 가리킨 다음 압정 아이콘을 클릭한다.
④ 점프 목록에서 항목을 제거하려면 프로그램의 점프 목록에서 항목을 가리킨 다음 Delete를 누른다.

정답: ④
해설: 점프 목록은 작업 표시줄의 앱 아이콘을 마우스 오른쪽 단추로 클릭해 열고, 항목을 클릭하면 해당 문서나 작업이 열린다. 압정 아이콘으로 항목을 고정할 수 있다. 항목 제거는 Delete 키가 아니라 해당 항목의 바로 가기 메뉴에서 ‘이 목록에서 제거’를 선택한다.


9. 다음 중 한글 Windows 10의 [파일 탐색기]에 대한 설명으로 옳지 않은 것은?

① 폴더와 파일을 계층 구조로 확인할 수 있다.
② [공유] 메뉴를 이용하여 사용자 전환이나 로그오프를 수행할 수 있다.
③ 파일 및 폴더를 복사하고, 옮기고, 이름을 바꾸고 검색할 수 있다.
④ 파일을 선택한 후에 바로 가기 메뉴에서 [인쇄]를 선택하면 해당 파일을 사용자가 직접 열지 않고 바로 인쇄할 수 있다.

정답: ②
해설: 파일 탐색기에서는 파일과 폴더를 계층적으로 보고 복사, 이동, 이름 변경, 검색 등을 할 수 있다. 연결된 프로그램이 지원하면 바로 가기 메뉴에서 인쇄할 수도 있다. 그러나 ‘공유’ 메뉴로 사용자 전환이나 로그오프를 수행할 수는 없다.


10. 다음 중 한글 Windows 10의 [폴더 옵션]에서 설정할 수 있는 작업에 해당되지 않는 것은?

① 숨김 파일 및 폴더를 표시할 수 있다.
② 색인된 위치에서는 파일 이름뿐만 아니라 내용도 검색하도록 설정할 수 있다.
③ 숨김 파일 및 폴더의 숨김 속성을 일괄 해제할 수 있다.
④ 파일이나 폴더를 한 번 클릭해서 열 것인지, 두 번 클릭해서 열 것인지를 설정할 수 있다.

정답: ③
해설: 폴더 옵션에서는 숨김 항목의 표시 여부, 검색 방식, 한 번 또는 두 번 클릭으로 항목 열기 등을 설정한다. 숨김 항목을 표시하는 것은 화면에 보이게 할 뿐 숨김 속성을 없애는 것이 아니다. 숨김 속성은 해당 파일이나 폴더의 ‘속성’ 창에서 해제해야 한다.


11. 다음 중 한글 Windows 10에서 하드디스크를 포맷하기 위한 [포맷] 창에서 설정 가능한 항목으로 옳지 않은 것은?

① 볼륨 레이블 입력
② 파티션 제거
③ 파일 시스템 선택
④ 빠른 포맷 선택

정답: ②
해설: 포맷 창에서는 볼륨 레이블, 파일 시스템, 할당 단위 크기, 빠른 포맷 여부 등을 지정할 수 있다. 파티션 제거는 포맷 옵션이 아니라 ‘디스크 관리’ 등의 파티션 관리 기능에서 수행한다.


12. 다음 중 폴더의 [속성] 창에 대한 설명으로 옳지 않은 것은?

① 폴더의 저장 위치를 변경할 수 있다.
② 폴더가 포함하고 있는 하위 폴더 및 파일의 개수를 알 수 있다.
③ 폴더에 ‘읽기 전용’ 속성을 설정하거나 해제할 수 있다.
④ 해당 폴더의 만든 날짜를 알 수 있다.

정답: ①
해설: 일반 폴더의 속성 창에서는 위치, 크기, 포함된 파일과 하위 폴더 수, 만든 날짜, 특성 등을 확인할 수 있지만 저장 위치를 임의로 변경할 수는 없다. 단, 문서나 다운로드 같은 일부 사용자 폴더에는 별도의 ‘위치’ 탭이 있을 수 있으나 이 문제는 일반 폴더를 기준으로 한다.



13. 다음 중 한글 Windows 10에서 작업 표시줄의 [검색 상자]에 대한 설명으로 옳지 않은 것은?

① 검색 항목은 모두, 앱, 문서, 웹, 동영상, 설정, 전자 메일, 폴더 등이다.
② 작업 표시줄의 바로 가기 메뉴에서 [검색]을 선택하여 검색 상자를 표시하거나 숨길 수 있다.
③ 검색된 앱을 선택하여 바로 실행할 수 있다.
④ Windows 키 + F를 누르면 검색 상자로 포커스가 옮겨진다.

정답: ④
해설: Windows 키 + F는 피드백 허브를 실행한다. 작업 표시줄 검색으로 포커스를 이동하는 단축키는 Windows 키 + S이다. 검색 상자는 작업 표시줄의 바로 가기 메뉴에서 표시하거나 숨길 수 있고, 검색된 앱은 바로 실행할 수 있다.


14. 다음 중 파일이나 폴더를 복사하거나 이동하는 방법으로 옳지 않은 것은?

① 폴더를 마우스로 선택한 후 동일한 드라이브의 다른 폴더로 끌어서 놓으면 이동이 된다.
② USB에 저장되어 있는 파일을 마우스로 선택한 후 바탕 화면으로 끌어서 놓으면 복사가 된다.
③ 파일을 마우스로 선택한 후 Ctrl을 누른 채 같은 드라이브의 다른 폴더로 끌어서 놓으면 복사가 된다.
④ 폴더를 마우스로 선택한 후 Alt를 누른 채 같은 드라이브의 다른 폴더로 끌어서 놓으면 이동이 된다.

정답: ④
해설: 같은 드라이브 안에서 끌어 놓으면 기본적으로 이동하고, 서로 다른 드라이브 사이에서는 기본적으로 복사한다. Ctrl을 누른 채 끌면 복사하고, Alt를 누른 채 끌면 이동이 아니라 바로 가기가 만들어진다.


15. 다음 중 한글 Windows 10의 클립보드에 대한 설명으로 가장 옳지 않은 것은?

① 클립보드는 Windows뿐만 아니라 설치된 모든 앱에서 공통으로 이용한다.
② 화면 전체 내용을 그대로 클립보드에 복사하는 키는 Print Screen이다.
③ 현재 사용 중인 활성창의 내용을 클립보드에 복사하는 키는 Ctrl + Print Screen이다.
④ 클립보드의 내용은 시스템을 재부팅하면 모두 삭제된다.

정답: ③
해설: Print Screen은 전체 화면을 클립보드에 복사하고, Alt + Print Screen은 현재 활성 창만 복사한다. 따라서 Ctrl + Print Screen이라고 한 ③이 틀렸다. 클립보드는 여러 프로그램이 함께 사용하는 임시 저장 공간이며, 전통적인 Windows 시험 기준에서는 시스템을 다시 시작하면 내용이 사라진다.


16. 다음 중 파일 삭제 시 파일이 [휴지통]에 임시 보관되어 복원이 가능한 경우는?

① 바탕 화면에 있는 파일을 [휴지통]으로 드래그 앤 드롭하여 삭제한 경우
② USB 메모리에 저장되어 있는 파일을 Delete로 삭제한 경우
③ 네트워크 드라이브의 파일을 바로 가기 메뉴의 [삭제]를 클릭하여 삭제한 경우
④ [휴지통]의 크기를 0%로 설정한 후 파일 탐색기 안의 파일을 삭제한 경우

정답: ①
해설: 로컬 드라이브의 파일을 휴지통으로 끌어 삭제하면 임시 보관되므로 복원할 수 있다. 일반적으로 USB 같은 이동식 저장 장치나 네트워크 드라이브에서 삭제한 파일은 휴지통에 보관되지 않는다. 휴지통 저장 공간을 0으로 설정한 경우에도 즉시 삭제된다.


17. 다음 중 한글 Windows 10의 [메모장]에 대한 설명으로 옳지 않은 것은?

① 작성한 문서를 저장할 때 확장자는 기본적으로 .txt가 부여된다.
② 특정한 문자열을 찾을 수 있는 찾기 기능이 있다.
③ 그림, 차트 등의 OLE 개체를 삽입할 수 있다.
④ 현재 시간을 삽입하는 기능이 있다.

정답: ③
해설: 메모장은 서식 없는 일반 텍스트 편집기이므로 그림이나 차트 같은 OLE 개체를 삽입할 수 없다. 기본 확장자는 .txt이고 문자열 찾기 기능이 있으며, F5 키 또는 ‘편집 → 시간/날짜’로 현재 시간과 날짜를 삽입할 수 있다.


18. 다음 중 Windows에서 사용하는 바로 가기 키에 대한 설명으로 옳은 것은?

① Alt + Delete : 휴지통을 거치지 않고 바로 삭제한다.
② Ctrl + Esc : [시작 화면]을 표시한다.
③ Alt + A : 모든 개체를 선택한다.
④ Ctrl + Tab : 실행된 프로그램 순서대로 전환한다.

정답: ②
해설: Ctrl + Esc는 시작 메뉴(문제 표현으로는 시작 화면)를 연다. 휴지통을 거치지 않고 삭제하는 키는 Shift + Delete이고, 모두 선택은 Ctrl + A이다. Ctrl + Tab은 한 프로그램 안의 탭이나 하위 창 전환에 주로 사용하며, 실행 중인 프로그램 사이의 순차 전환은 Alt + Esc를 사용한다.


19. 한글 Windows 10의 [휴지통]에 관한 설명으로 옳지 않은 것은?

① 휴지통의 실제 파일이 저장된 폴더의 위치는 일반적으로 C:\$Recycle.Bin이다.
② 휴지통에 보관된 파일은 삭제된 위치, 삭제된 날짜와 시간, 크기 등의 정보를 갖는다.
③ 휴지통에 보관된 파일은 이름을 변경하거나 실행할 수 없다.
④ 휴지통의 크기는 드라이브 용량의 10%~20% 범위 안에서 시스템이 자동으로 설정하며, 변경할 수 없다.

정답: ④
해설: 휴지통 데이터는 일반적으로 각 드라이브의 숨김 시스템 폴더인 $Recycle.Bin에 저장된다. 휴지통에서는 원래 위치, 삭제 날짜와 시간, 크기 등의 정보를 확인할 수 있으며, 보관된 파일은 직접 실행하거나 이름을 바꿀 수 없다. 휴지통의 최대 크기는 속성 창에서 드라이브별로 MB 단위로 변경할 수 있으므로 ‘변경할 수 없다’는 ④가 틀렸다. Windows 버전과 드라이브 크기에 따라 기본 할당 방식이 달라질 수 있으므로 비율보다 사용자가 크기를 변경할 수 있다는 점이 핵심이다.
