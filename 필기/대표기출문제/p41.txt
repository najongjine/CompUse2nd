컴퓨터활용능력 2급 필기 대표 기출문제
※ 각 문항의 보기 바로 아래에 정답과 자세한 해설을 배치했습니다.


1. 다음 설명의 ㉠, ㉡, ㉢에 해당하는 소프트웨어의 종류를 바르게 나열한 것은?

철수는 어떤 프로그램이 좋은지 알아보기 위해 ㉠ 무료로 자유롭게 사용할 수 있는 프로그램과 ㉡ 주로 일정 기간 또는 일부 기능만 사용할 수 있도록 배포된 프로그램을 먼저 사용해 보고, 가장 적합한 ㉢ 프로그램을 정식으로 구매하여 사용하려고 한다.

① ㉠ 프리웨어, ㉡ 셰어웨어, ㉢ 상용 소프트웨어
② ㉠ 셰어웨어, ㉡ 프리웨어, ㉢ 상용 소프트웨어
③ ㉠ 상용 소프트웨어, ㉡ 셰어웨어, ㉢ 프리웨어
④ ㉠ 셰어웨어, ㉡ 상용 소프트웨어, ㉢ 프리웨어

[정답] ①

[해설]
무료로 자유롭게 사용할 수 있도록 배포하는 프로그램은 프리웨어, 일정 기간이나 일부 기능만 시험 사용할 수 있도록 배포하는 프로그램은 셰어웨어이다. 정식 대가를 지급하고 구매하여 사용하는 프로그램은 상용 소프트웨어이다.

- 프리웨어(Freeware): 저작권자가 무료 사용을 허용한 소프트웨어이다.
- 셰어웨어(Shareware): 구매 전에 일정 기간 또는 제한된 기능을 시험해 볼 수 있게 배포하는 소프트웨어이다.
- 상용 소프트웨어(Commercial Software): 판매를 목적으로 개발되어 사용권을 구매해야 하는 소프트웨어이다.

[주의]
프리웨어라고 해서 저작권이 없는 것은 아니다. 무료로 사용할 수 있을 뿐, 저작권자가 정한 복제·배포·수정 조건은 지켜야 한다. 오픈 소스 소프트웨어도 반드시 무료인 것은 아니며, 프리웨어와 같은 뜻이 아니다.


2. 다음 중 운영체제에 대한 설명으로 옳지 않은 것은?

① 운영체제는 제어 프로그램, 감시 프로그램, 응용 프로그램으로 구성된다.
② 자원을 효율적으로 관리하기 위해 자원의 스케줄링 기능을 제공한다.
③ 시스템과 사용자 사이에서 편리한 인터페이스를 제공한다.
④ 데이터 및 시스템 자원의 공유 기능을 제공한다.

[정답] ①

[해설]
운영체제는 크게 제어 프로그램(Control Program)과 처리 프로그램(Processing Program)으로 구분한다. 응용 프로그램은 운영체제 위에서 사용자의 특정 업무를 처리하는 소프트웨어이므로 운영체제의 구성 요소가 아니다.

- ① 틀림: ‘제어 프로그램과 처리 프로그램’으로 구성한다고 보는 것이 맞다. 감시 프로그램은 제어 프로그램에 속한다.
- ② 옳음: CPU, 메모리, 입출력장치 등의 사용 순서와 시간을 조정한다.
- ③ 옳음: 사용자가 하드웨어를 편리하게 이용할 수 있도록 사용자 인터페이스를 제공한다.
- ④ 옳음: 여러 사용자나 프로그램이 데이터와 하드웨어 자원을 공유하도록 관리한다.

[구성 정리]
- 제어 프로그램: 감시 프로그램, 작업 관리 프로그램, 데이터 관리 프로그램
- 처리 프로그램: 언어 번역 프로그램, 서비스 프로그램, 문제 처리 프로그램

[핵심 정리]
운영체제의 주요 목적은 처리 능력 향상, 응답 시간 단축, 사용 가능도 향상, 신뢰도 향상이다.


3. 다음 중 유틸리티 프로그램에 대한 설명으로 적절하지 않은 것은?

① 다수의 작업이나 특정 대상을 위한 편리한 서비스 프로그램 또는 루틴을 말한다.
② 컴퓨터의 동작에 필수적이며, 컴퓨터를 이용하는 주목적에 해당하는 특정 작업을 수행하는 소프트웨어를 말한다.
③ 컴퓨터의 하드웨어, 운영체제, 응용 소프트웨어를 관리하거나 지원하는 것을 주목적으로 설계된 프로그램을 말한다.
④ Windows에서 제공하는 유틸리티 프로그램의 예로 메모장, 그림판, 계산기 등을 들 수 있다.

[정답] ②

[해설]
유틸리티 프로그램은 사용자가 컴퓨터를 보다 편리하고 효율적으로 관리하도록 돕는 보조 프로그램이다. 일반적으로 컴퓨터의 기본 동작에 반드시 필요한 프로그램은 아니며, 사용자의 주된 업무 자체를 처리하는 응용 프로그램과도 구별된다.

- ① 옳음: 반복 작업이나 관리 작업을 편리하게 수행하도록 돕는다.
- ② 틀림: 유틸리티는 보조 목적의 프로그램이며, 컴퓨터의 동작에 반드시 필요한 것은 아니다.
- ③ 옳음: 시스템 점검, 파일 관리, 백업, 압축, 보안 등의 작업을 지원한다.
- ④ 옳음: 시험 교재에서는 메모장, 그림판, 계산기 등을 Windows의 보조 프로그램 또는 유틸리티 프로그램의 예로 분류한다.

[대표적인 유틸리티]
백신 프로그램, 파일 압축 프로그램, 백업 프로그램, 디스크 검사·정리 프로그램, 화면 캡처 프로그램 등이 있다.


4. 다음 중 운영체제의 운용 방식에 대한 설명으로 옳지 않은 것은?

① 일괄 처리 시스템은 입력 데이터를 일정량 모아 한꺼번에 처리하는 방식으로, 오프라인에서만 사용한다.
② 시분할 시스템은 한 대의 시스템을 여러 사용자가 동시에 사용하는 것처럼 처리하는 방식이다.
③ 실시간 처리 시스템은 처리할 데이터가 발생하면 정해진 시간 안에 즉시 처리하여 결과를 제공하는 방식이다.
④ 분산 처리 시스템은 지역적으로 분산된 여러 컴퓨터를 통신망으로 연결하여 작업을 나누어 처리하는 방식이다.

[정답] ①

[해설]
일괄 처리 시스템은 유사한 작업이나 데이터를 일정량 모은 뒤 한꺼번에 처리하는 방식이다. 작업을 모아 두었다가 처리한다는 점이 핵심이며, 반드시 오프라인에서만 사용하는 것은 아니다. 따라서 ①의 뒷부분이 잘못되었다.

- ① 틀림: 일괄 처리는 온라인 환경에서도 사용할 수 있다.
- ② 옳음: CPU 시간을 매우 짧은 시간 단위로 나누어 여러 사용자에게 번갈아 할당한다.
- ③ 옳음: 결과가 정해진 제한 시간 안에 나와야 하는 시스템에 사용한다.
- ④ 옳음: 여러 컴퓨터가 작업을 분담하므로 자원 공유와 처리 능력 향상에 유리하다.

[예시]
- 일괄 처리: 급여 계산, 수도·전기 요금 계산
- 시분할 처리: 여러 사용자가 동시에 접속하는 서버
- 실시간 처리: 항공권 예약, 공정 제어, 의료 감시 시스템
- 분산 처리: 여러 지역의 컴퓨터가 네트워크로 연결되어 하나의 업무를 분담하는 시스템

[주의]
항공권 예약은 사용자의 요청에 즉시 응답한다는 관점에서 온라인 실시간 처리의 대표 사례로 분류한다.


5. 다음 중 추상화, 캡슐화, 상속성, 다형성 등의 특징을 가지며, 크고 복잡한 프로그램을 구축하기 어려웠던 기존 절차적 언어의 문제점을 해결하기 위해 개발된 프로그래밍 기법은?

① 구조적 프로그래밍
② 객체지향 프로그래밍
③ 순차적 프로그래밍
④ 비주얼 프로그래밍

[정답] ②

[해설]
객체지향 프로그래밍(Object-Oriented Programming)은 데이터와 그 데이터를 처리하는 기능을 객체로 묶어 프로그램을 구성하는 방식이다. 추상화, 캡슐화, 상속성, 다형성이 핵심 특징이다.

- ① 구조적 프로그래밍: 프로그램을 순차, 선택, 반복의 제어 구조와 여러 모듈로 구성하는 방식이다.
- ② 객체지향 프로그래밍: 객체들의 상호작용을 중심으로 프로그램을 구성한다.
- ③ 순차적 프로그래밍: 명령을 작성된 순서에 따라 차례로 실행하는 방식이다.
- ④ 비주얼 프로그래밍: 아이콘, 메뉴, 다이어그램 같은 시각적 요소를 이용해 프로그램을 개발하는 방식이다.

[객체지향 핵심 개념]
- 추상화: 객체의 공통적이고 중요한 특징만 뽑아 표현하는 것
- 캡슐화: 데이터와 관련 메서드를 하나로 묶고 내부 구현을 감추는 것
- 상속성: 기존 클래스의 속성과 기능을 새로운 클래스가 물려받는 것
- 다형성: 같은 명령이나 인터페이스가 객체에 따라 다르게 동작하는 것

[장점]
코드의 재사용과 유지보수가 쉽고, 대규모 프로그램을 기능별 객체로 나누어 개발하기 좋다.


6. 다음 중 차세대 웹 표준으로, 텍스트와 하이퍼링크 중심으로 구성된 기존 웹 표준에 비디오·오디오 등 다양한 부가 기능을 추가하여 최신 멀티미디어 콘텐츠를 ActiveX 없이 웹 서비스로 제공할 수 있게 한 언어는?

① XML
② VRML
③ HTML5
④ JSP

[정답] ③

[해설]
HTML5는 웹 문서의 구조를 표현하는 HTML의 발전된 표준이다. `<audio>`, `<video>`, `<canvas>` 등의 요소와 다양한 웹 API를 제공하여 별도의 ActiveX나 플러그인에 덜 의존하면서 멀티미디어와 웹 애플리케이션을 구현할 수 있다.

- ① XML: 사용자가 태그를 정의하여 구조화된 데이터를 표현하고 교환하는 언어이다.
- ② VRML: 웹에서 3차원 가상 공간과 객체를 표현하기 위해 개발된 언어이다.
- ③ HTML5: 웹 문서와 멀티미디어 콘텐츠를 표현하는 웹 표준이다.
- ④ JSP: Java를 이용하여 서버에서 동적인 웹 페이지를 생성하는 서버 측 기술이다.

[주의]
HTML5는 단순히 동영상 재생만을 위한 언어가 아니다. 문서의 의미 구조, 그래픽, 멀티미디어, 로컬 저장소 등 현대적인 웹 애플리케이션 기능을 폭넓게 지원한다.


7. 다음 중 웹 프로그래밍 언어 또는 웹 문서 관련 언어에 대한 설명으로 옳지 않은 것은?

① ASP는 주로 Windows 계열의 웹 서버 환경에서 사용하며, JSP와 PHP는 다양한 운영체제 환경에서 사용할 수 있다.
② XML은 HTML의 단점을 보완하여 구조화된 다양한 문서를 작성하고 서로 다른 시스템 사이에서 데이터를 교환할 수 있도록 설계된 언어이다.
③ SGML은 다양한 형태의 전자 문서를 서로 다른 시스템에서 효율적으로 전송·저장·처리할 수 있도록 문서의 구조를 정의하는 메타언어이다.
④ DHTML은 가상현실 모델링 언어로, 웹에서 3차원 가상 공간을 표현하고 조작할 수 있게 하는 언어이다.

[정답] ④

[해설]
웹에서 3차원 가상 공간과 객체를 표현하기 위한 언어는 VRML(Virtual Reality Modeling Language)이다. DHTML은 별도의 단일 언어가 아니라 HTML, CSS, JavaScript 등을 조합하여 웹 페이지의 내용과 모양을 동적으로 바꾸는 기술을 뜻한다.

- ① 옳음: 전통적인 시험 분류에서 ASP는 Microsoft의 IIS 및 Windows 환경과 밀접하고, JSP와 PHP는 여러 운영체제에서 사용할 수 있는 서버 측 기술로 본다.
- ② 옳음: XML은 사용자가 목적에 맞는 태그를 정의할 수 있어 구조화된 데이터의 표현과 교환에 적합하다.
- ③ 옳음: SGML은 문서의 논리적 구조와 태그 작성 규칙을 정의할 수 있는 메타언어이며 HTML과 XML의 기반이 되었다.
- ④ 틀림: 설명한 기술은 VRML이다. DHTML은 동적인 웹 페이지를 구현하는 기술의 통칭이다.

[용어 비교]
- HTML: 웹 문서의 구조와 내용을 표현
- XML: 구조화된 데이터의 저장과 교환
- DHTML: HTML·CSS·JavaScript를 이용한 동적 웹 페이지 구현
- VRML: 웹 기반 3차원 가상 공간 표현
- ASP·JSP·PHP: 서버에서 동적인 웹 페이지를 생성하는 기술
