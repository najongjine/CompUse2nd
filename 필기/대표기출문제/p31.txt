1. 다음 중 소형화, 경량화를 비롯해 음성과 동작인식 등 다양한
기능이 적용되어 장소에 구애받지 않고 컴퓨터를 활용할 수 있도록
몸에 착용하는 컴퓨터를 의미하는 것은?

① 웨어러블 컴퓨터
② 마이크로 컴퓨터
③ 인공지능 컴퓨터
④ 서버 컴퓨터

정답: ①
해설: 웨어러블 컴퓨터(Wearable Computer)는 시계, 안경, 의복처럼 몸에 착용하여 이동 중에도 사용할 수 있는 컴퓨터이다. 소형·경량화되어 있으며 센서, 음성 인식, 동작 인식 등을 이용해 사용자나 주변 환경의 정보를 처리한다. 스마트워치와 스마트 글라스가 대표적인 예이다. 마이크로 컴퓨터(②)는 마이크로프로세서를 중앙 처리 장치로 사용하는 소형 컴퓨터의 분류이고, 인공지능 컴퓨터(③)는 인간의 학습·추론 등을 구현하는 컴퓨터를 가리킨다. 서버 컴퓨터(④)는 네트워크에서 다른 컴퓨터에 자료나 서비스를 제공한다.


2. 다음 중 디지털 컴퓨터와 아날로그 컴퓨터의 차이점에 관한
설명으로 옳은 것은?

① 디지털 컴퓨터는 전류, 전압을 온도 또는 다양한 입력 값을 처리하며,
   아날로그 컴퓨터는 숫자 데이터를 처리한다.
② 디지털 컴퓨터는 증폭 회로로 구성되며, 아날로그 컴퓨터는
   논리 회로로 구성된다.
③ 아날로그 컴퓨터는 미분이나 적분 연산을 주로 하며,
   디지털 컴퓨터는 산술이나 논리 연산을 주로 한다.
④ 아날로그 컴퓨터는 범용이며, 디지털 컴퓨터는 특수 목적용으로
   많이 사용된다.

정답: ③
해설: 아날로그 컴퓨터는 전압, 전류, 온도, 속도처럼 연속적으로 변하는 물리량을 처리하며 미분·적분 연산에 적합하다. 디지털 컴퓨터는 숫자나 문자처럼 이산적인 데이터를 0과 1로 표현하여 산술·논리 연산을 수행하므로 ③이 옳다. ①은 두 컴퓨터의 처리 대상을 반대로 설명했고, ②도 회로 구성을 반대로 설명했다. 디지털 컴퓨터는 논리 회로, 아날로그 컴퓨터는 증폭 회로를 주로 사용한다. 또한 디지털 컴퓨터는 여러 분야에 쓰이는 범용, 아날로그 컴퓨터는 특정한 목적에 맞춘 특수 목적용으로 주로 사용하므로 ④도 반대이다.


3. 다음 중 자료의 구성 단위에 대한 설명으로 옳지 않은 것은?

① 워드(Word)는 명령 처리 단위이며, 전워드(Full Word)는
   8Byte이다.
② 필드(Field)는 파일 구성의 최소 단위이다.
③ 니블(Nibble)은 4개의 비트로 16가지를 표현할 수 있다.
④ 여러 개의 파일이 모여 데이터베이스가 된다.

정답: ①
해설: 워드(Word)는 CPU가 한 번에 처리할 수 있는 명령이나 자료의 단위이며, 이 문제에서 사용하는 분류상 반워드(Half Word)는 2Byte, 전워드(Full Word)는 4Byte, 더블워드(Double Word)는 8Byte이다. 따라서 전워드가 8Byte라는 ①이 틀리다. 필드는 파일을 구성하는 의미 있는 최소 단위이고(②), 니블은 4bit이므로 2⁴인 16가지 정보를 표현한다(③). 자료의 논리적 구성 순서는 일반적으로 필드 → 레코드 → 파일 → 데이터베이스이므로 ④도 옳다. 참고로 실제 컴퓨터에서 ‘워드’의 크기는 CPU 구조에 따라 달라질 수 있지만, 이 문항은 시험의 자료 단위 분류를 기준으로 판단한다.


4. 다음 중 컴퓨터에서 문자 데이터를 표현하는 방법으로 옳지
않은 것은?

① EBCDIC
② Unicode
③ ASCII
④ Hamming Code

정답: ④
해설: ASCII, EBCDIC, Unicode는 문자에 고유한 값을 부여하여 컴퓨터가 문자를 저장하고 교환할 수 있게 하는 문자 표현 코드이다. ASCII(③)는 기본적으로 7bit 문자 코드이고, EBCDIC(①)은 주로 IBM 계열 대형 컴퓨터에서 사용된 8bit 문자 코드이다. Unicode(②)는 세계 여러 언어의 문자를 하나의 체계로 표현하기 위한 국제 문자 표준이다. Hamming Code(④)는 데이터에 검사 비트를 추가해 전송·저장 과정의 비트 오류를 검출하고 교정하는 오류 제어 코드이므로 문자 표현 방식이 아니다.


5. 다음 중 컴퓨터에서 사용하는 유니코드(Unicode)에 관한 설명
으로 옳은 것은?

① 표현 가능한 문자수는 최대 256자이다.
② 문자를 2Byte로 표현한다.
③ 영문자를 7bit, 한글이나 한자를 16bit로 처리한다.
④ 한글은 KS 완성형으로 표현한다.

정답: ②
해설: 이 문항의 출제 기준에서는 Unicode를 세계 각국의 문자를 통일하여 표현하기 위한 16bit, 즉 2Byte 국제 표준 문자 코드로 설명하므로 ②가 정답이다. 2Byte이면 2¹⁶인 65,536개의 값을 구분할 수 있으므로 최대 256자라는 ①은 틀리다. 영문자를 7bit로 표현하는 것은 ASCII의 특징이므로 ③도 틀리며, Unicode는 특정한 한국어 문자 코드인 KS 완성형만을 사용하는 방식이 아니므로 ④도 틀리다. 다만 현대의 정확한 개념으로는 Unicode는 문자마다 ‘코드 포인트’를 부여하는 표준이고, 실제 저장 크기는 UTF-8·UTF-16·UTF-32 중 어떤 인코딩을 쓰느냐에 따라 달라진다. 따라서 모든 Unicode 문자가 현실에서 항상 2Byte인 것은 아니지만, 이 문제에서는 교재의 전통적인 16bit 설명에 따라 ②를 고른다.
