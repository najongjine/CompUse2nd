1. 다음 중 한글 Windows 10의 [설정] → [시스템] → [디스플레이]에서 해상도 조정 설정에 대한 설명으로 옳지 않은 것은?
24상시, 23상시, 22상시, 14.3

① 높은 화면 해상도에서는 텍스트와 이미지가 더 선명하지만 크기는 더 작게 표시된다.
② 해상도를 변경하면 해당 컴퓨터에 로그인한 모든 사용자에게 변경 내용이 적용된다.
③ 여러 디스플레이 옵션은 Windows에서 둘 이상의 모니터가 PC에 연결되어 있음을 인식할 때만 나타난다.
④ 두 대의 모니터가 연결된 경우 좌측 모니터가 주 모니터로 설정되므로 해상도가 높은 모니터를 반드시 좌측에 배치해야 한다.

정답: ④
해설: 모니터의 실제 좌우 위치와 주 모니터 지정은 서로 별개의 설정이다. [설정] → [시스템] → [디스플레이]에서 원하는 모니터를 선택한 뒤 ‘이 디스플레이를 주 모니터로 만들기’를 설정할 수 있으므로, 해상도가 높은 모니터를 반드시 왼쪽에 둘 필요가 없다. 해상도가 높아지면 한 화면에 표시되는 정보량이 많아져 글자와 그림이 상대적으로 작고 선명하게 보이며(①), 해상도 설정은 장치의 디스플레이 설정이므로 모든 사용자에게 적용된다(②). ‘여러 디스플레이’ 관련 옵션은 둘 이상의 디스플레이가 인식된 경우에 사용할 수 있다(③).


2. 다음 중 한글 Windows 10의 [설정] → [시스템] → [소리]에서 수행할 수 있는 작업이 아닌 것은?
24상시, 23상시, 22상시

① 출력 장치를 선택할 수 있다.
② 입력 장치를 선택할 수 있다.
③ 마스터 볼륨을 조절할 수 있다.
④ 내레이터를 설정할 수 있다.

정답: ④
해설: [소리]에서는 스피커·헤드폰 같은 출력 장치, 마이크 같은 입력 장치, 마스터 볼륨 등을 설정할 수 있으므로 ①~③은 수행할 수 있다. 화면의 글자와 항목을 음성으로 읽어 주는 ‘내레이터’는 시각 지원 기능이므로 [설정] → [접근성] → [내레이터]에서 설정한다.


3. 다음은 [설정] → [개인 설정]에 관한 설명이다. 다음 중 옳지 않은 것은?
24상시, 23상시, 22상시, 07.2, 06.3, 05.2

① 바탕 화면의 배경을 사용자가 임의로 바꿀 수 있게 지원한다.
② 시스템을 켠 채 정해진 시간 동안 마우스나 키보드를 사용하지 않으면 모니터를 보호하기 위해 화면 보호기를 작동할지 여부를 설정한다.
③ 창의 색상과 구성 요소의 색상을 설정한다.
④ 모니터의 해상도 및 방향을 설정한다.

정답: ④
해설: [개인 설정]에서는 배경, 색, 잠금 화면, 테마, 글꼴, 시작 메뉴, 작업 표시줄 등 화면의 모양을 사용자 취향에 맞게 바꾼다. 화면 보호기 설정도 잠금 화면의 관련 설정에서 열 수 있으므로 ①~③은 옳다. 모니터의 해상도와 가로·세로 방향은 장치의 출력 방식에 관한 항목이므로 [설정] → [시스템] → [디스플레이]에서 설정한다.


4. 다음 중 Windows의 [설정] → [앱]에서 설정할 수 없는 기능은?
23상시, 21상시

① 선택적 기능을 설치하거나 제거할 수 있다.
② 시작 프로그램을 확인할 수 있다.
③ 업데이트 현황을 확인하거나 설정할 수 있다.
④ 설치된 앱을 변경하거나 제거할 수 있다.

정답: ③
해설: [설정] → [앱]에서는 설치된 앱의 변경·제거, 선택적 기능의 추가·제거, 시작 프로그램 관리 등을 할 수 있으므로 ①, ②, ④는 옳다. Windows 업데이트의 확인, 다운로드 및 관련 설정은 [설정] → [업데이트 및 보안] → [Windows 업데이트]에서 수행한다.


5. 다음 중 Windows 10의 연결 프로그램에 대한 설명으로 옳지 않은 것은?
25상시, 24상시, 23상시, 22상시, 21상시, 13.3, 08.3, 04.3

① 파일 탐색기에서 특정한 파일을 더블클릭했을 때 실행될 앱을 설정하는 것이다.
② 확장자가 .txt나 .hwp인 파일은 반드시 서로 다른 연결 프로그램이 지정되어야 한다.
③ 동일한 확장자를 가진 다른 파일을 열 때 항상 같은 앱을 사용하도록 연결 프로그램을 설정할 수 있다.
④ 일반적으로 앱을 설치하면 해당 앱에서 사용하는 파일은 연결 프로그램이 자동으로 설정된다.

정답: ②
해설: 연결 프로그램은 특정 파일 형식(확장자)을 열 때 사용할 기본 앱을 정하는 기능이다. 같은 확장자의 파일을 항상 같은 앱으로 열게 할 수 있고(①, ③), 앱 설치 과정에서 지원 파일 형식이 자동 연결되기도 한다(④). 그러나 서로 다른 확장자라도 한 앱이 두 형식을 모두 지원하면 같은 앱에 연결할 수 있다. 예를 들어 메모장으로 여러 종류의 텍스트 기반 파일을 열 수 있으므로 .txt와 .hwp가 반드시 서로 다른 프로그램에 연결되어야 한다는 ②는 틀리다.


6. 다음 중 한글 Windows 10의 [설정] → [접근성]에서 설정할 수 없는 기능은?
25상시, 24상시, 23상시, 20.2

① 다중 디스플레이를 설정하여 두 대의 모니터에 화면을 확장하여 표시할 수 있다.
② 돋보기를 사용하여 화면에서 원하는 영역을 확대하여 크게 표시할 수 있다.
③ 내레이터를 사용하여 화면의 모든 텍스트를 소리내어 읽어 주도록 설정할 수 있다.
④ 키보드가 없어도 입력 가능한 화상 키보드를 표시할 수 있다.

정답: ①
해설: [접근성]은 장애가 있거나 컴퓨터 사용이 불편한 사용자를 돕는 기능을 모아 둔 곳이다. 화면을 확대하는 돋보기(②), 화면 내용을 읽어 주는 내레이터(③), 마우스로 입력할 수 있는 화상 키보드(④)를 설정할 수 있다. 두 모니터에 화면을 복제하거나 확장하는 다중 디스플레이 설정은 [설정] → [시스템] → [디스플레이]에서 한다.


7. 다음 중 한글 Windows 10의 사용자 계정을 통해 사용할 수 있는 기능으로 옳지 않은 것은?
20상시, 20.1

① 관리자 계정의 사용자는 다른 계정의 컴퓨터 사용 시간을 제어할 수 있다.
② 관리자 계정의 사용자는 제한 없이 컴퓨터 설정을 변경할 수 있다.
③ 표준 사용자 계정의 사용자는 컴퓨터 보안에 영향을 주는 설정을 변경할 수 있다.
④ 표준 사용자 계정의 사용자는 컴퓨터에 설치된 대부분의 앱을 사용할 수 있다.

정답: ③
해설: 표준 사용자 계정은 설치된 대부분의 앱을 사용할 수 있지만(④), 시스템 전체나 다른 사용자에게 영향을 주는 보안 설정 변경에는 관리자 권한이 필요하다. 따라서 표준 사용자가 컴퓨터 보안에 영향을 주는 설정을 변경할 수 있다는 ③이 틀리다. 관리자는 컴퓨터 설정을 폭넓게 변경할 수 있고(②), 자녀 계정 등의 사용 시간 제한도 관리할 수 있다(①). 권한이 필요한 작업에서는 사용자 계정 컨트롤의 확인 절차가 나타날 수 있다.


8. 다음 중 한글 Windows 10에서 유해한 앱이나 불법 사용자가 컴퓨터 설정을 임의로 변경하려는 경우 이를 사용자에게 알려 컴퓨터를 제어할 수 있도록 도와주는 기능은?
24상시, 19.2, 16.1

① 사용자 계정 컨트롤
② Windows Defender
③ BitLocker
④ 시스템 복원

정답: ①
해설: 사용자 계정 컨트롤(UAC)은 앱이 관리자 권한이 필요한 변경을 시도할 때 알림을 띄워 사용자가 허용 여부를 결정하게 한다. Windows Defender는 악성 코드 방지, BitLocker는 드라이브 암호화, 시스템 복원은 시스템 파일과 설정을 이전 복원 지점으로 되돌리는 기능이므로 문제의 설명과 다르다.


9. 다음 중 한글 Windows 10에서 외부로부터의 불법적인 해킹 등의 위험 요소로부터 컴퓨터를 보호하는 역할을 하는 것은 무엇인가?
23상시, 22상시, 21상시

① Windows Update
② Windows Defender 방화벽
③ BitLocker
④ Malware

정답: ②
해설: Windows Defender 방화벽은 네트워크를 통해 들어오고 나가는 통신을 규칙에 따라 허용하거나 차단하여 외부 침입 위험을 줄인다. Windows Update는 운영체제의 업데이트 기능이고, BitLocker는 저장 장치의 데이터를 암호화한다. Malware는 컴퓨터에 피해를 주는 악성 소프트웨어의 통칭이지 보호 기능의 이름이 아니다.


10. 다음 중 [설정] → [장치] → [마우스]에서 설정할 수 있는 기능으로 옳지 않은 것은?
23상시

① 왼손잡이와 오른손잡이의 마우스 단추 기능을 설정할 수 있다.
② 활성창/비활성 창 구분 없이 마우스 포인터가 가리키는 창이 스크롤 되도록 설정할 수 있다.
③ 휠을 한 번 돌리면 여러 줄(10~50) 또는 한 화면이 스크롤 되도록 설정할 수 있다.
④ 마우스 커서의 속도를 설정할 수 있다.

정답: ③
해설: [설정] → [장치] → [마우스]에서는 기본 단추를 왼쪽 또는 오른쪽으로 지정하고(①), 비활성 창 위에 포인터를 놓았을 때 그 창을 스크롤할지 설정하며(②), 커서 속도도 조절할 수 있다(④). 휠 한 번에 스크롤할 양은 ‘한 번에 여러 줄’ 또는 ‘한 화면씩’으로 정할 수 있으며, 줄 수의 범위는 1~100줄이다. 따라서 10~50줄이라고 한 ③이 틀리다.


11. 다음 중 한글 Windows 10에서 사용자 컴퓨터에 설치된 하드웨어의 종류 및 작동 여부를 확인하거나 하드웨어 제거를 수행할 수 있는 항목은?
25상시, 24상시, 23상시, 15.3

① [제어판] → [시스템]
② [제어판] → [관리 도구]
③ [제어판] → [프로그램 및 기능]
④ [제어판] → [장치 관리자]

정답: ④
해설: 장치 관리자는 컴퓨터에 설치된 하드웨어를 종류별로 보여 주며, 장치의 정상 작동 여부 확인, 드라이버 업데이트·제거, 장치 사용·사용 안 함, 하드웨어 제거 등을 수행한다. [시스템]은 컴퓨터의 기본 정보, [관리 도구]는 여러 시스템 관리 도구, [프로그램 및 기능]은 설치 프로그램의 변경·제거에 주로 사용한다.


12. 다음 중 한글 Windows 10에서 프린터 설치에 관한 설명으로 옳지 않은 것은?
23상시, 22상시, 21상시, 19.1

① 네트워크 프린터를 선택한 경우에는 연결할 프린터의 포트를 지정한다.
② [설정] → [장치] → [프린터 및 스캐너]에서 프린터 또는 스캐너 추가를 클릭하여 프린터를 추가한다.
③ 설치할 프린터 유형은 로컬 프린터와 Bluetooth, 무선 또는 네트워크 검색 가능 프린터 중에서 하나를 선택할 수 있다.
④ 컴퓨터에 설치된 여러 프린터 중에 현재 설치 중인 프린터를 기본 프린터로 설정할 것인지 선택한다.

정답: ①
해설: Windows 10에서는 [설정] → [장치] → [프린터 및 스캐너]에서 프린터 또는 스캐너를 추가하며(②), 로컬 프린터 또는 Bluetooth·무선·네트워크 프린터를 선택해 설치할 수 있다(③). 설치 과정에서 기본 프린터 지정 여부도 선택할 수 있다(④). 검색된 네트워크 프린터를 선택하면 연결에 필요한 포트가 자동으로 지정되므로 사용자가 반드시 포트를 직접 지정한다는 ①은 틀리다.



13. 한글 Windows 10의 기본 프린터에 대한 설명으로 가장 옳지 않은 것은?
18상시, 15.2, 11.2, 08.2, 07.1, 03.3, 02.2, 00.3

① 특정한 프린터를 설정하지 않을 경우 자동으로 인쇄 작업을 처리하는 프린터이다.
② 기본 프린터는 한 대만 지정할 수 있다.
③ 기본 프린터에는 프린터 이름 아래에 ‘기본값’이라고 표시된다.
④ 네트워크 프린터는 기본 프린터로 설정할 수 없다.

정답: ④
해설: 기본 프린터는 인쇄할 때 별도의 프린터를 지정하지 않으면 자동으로 선택되는 프린터이며(①), 한 번에 한 대만 지정할 수 있다(②). 기본 프린터에는 이름 아래에 ‘기본값’이 표시된다(③). 로컬 프린터뿐 아니라 정상적으로 연결된 네트워크 프린터도 기본 프린터로 지정할 수 있으므로 ④가 틀리다.

25상시, 24상시, 23상시

① 기본 프린터를 2대 이상 지정할 수 있다.
② 프린터 속성 창에서 공급 용지의 종류, 공유, 포트 등을 설정할 수 있다.
③ 인쇄 대기 중인 작업을 취소시킬 수 없다.
④ 인쇄 중인 작업은 취소할 수는 없으나 잠시 중단시킬 수 있다.

정답: ②
해설: 프린터 속성에서는 용지 관련 장치 설정, 프린터 공유 여부, 사용할 포트 등 프린터의 구성 정보를 설정할 수 있으므로 ②가 옳다. 기본 프린터는 한 대만 지정할 수 있어 ①은 틀리다. 인쇄 대기열에서는 대기 중이거나 인쇄 중인 문서를 일시 중지하거나 취소할 수 있으므로 ③과 ④도 틀리다. 단, 취소 명령 후 이미 프린터로 전송된 일부 내용은 잠시 더 출력될 수 있다.


15. 다음 중 한글 Windows 10의 드라이브 조각 모음 및 최적화 기능에 관한 설명으로 옳지 않은 것은?
25상시, 23상시, 21상시, 19.2

① 하드디스크에 단편화되어 조각난 파일들을 모아준다.
② USB 플래시 드라이브와 같은 이동식 저장장치도 드라이브 조각 모음을 수행할 수 있다.
③ 수행 후에는 디스크 공간의 최적화가 이루어져 디스크의 용량이 증가한다.
④ 일정을 구성하여 드라이브 조각 모음 및 최적화를 예약 실행할 수 있다.

정답: ③
해설: 조각 모음은 하드디스크 곳곳에 흩어진 파일 조각을 가능한 한 연속된 공간에 배치하여 접근 효율을 높이는 작업이다(①). 이동식 저장 장치도 해당 기능의 대상이 될 수 있으며(②), 예약 일정을 정해 자동으로 최적화할 수도 있다(④). 파일을 삭제하거나 저장 장치의 물리적 용량을 늘리는 기능은 아니므로 작업 후 디스크 용량이 증가한다는 ③은 틀리다. 참고로 SSD는 HDD처럼 파일 조각을 재배치하기보다 Windows가 장치 종류에 맞는 최적화(TRIM 등)를 수행한다.


16. 다음 중 한글 Windows 10의 ‘작업 관리자’ 대화상자에서 수행할 수 있는 작업으로 옳지 않은 것은?
22상시, 21상시

① 컴퓨터를 이용하는 사용자 계정의 추가와 삭제를 수행할 수 있다.
② 현재 실행 중인 앱을 강제로 종료시킬 수 있다.
③ 시스템의 CPU 사용 내용이나 할당된 메모리의 크기를 확인할 수 있다.
④ 현재 네트워크 상태를 보고 네트워크 처리량을 확인할 수 있다.

정답: ①
해설: 작업 관리자에서는 실행 중인 앱과 프로세스를 확인해 강제 종료할 수 있고(②), [성능] 탭에서 CPU·메모리 사용량(③)과 네트워크 처리량(④)을 확인할 수 있다. [사용자] 탭은 현재 로그인한 사용자의 자원 사용 상태를 보여 주고 연결을 끊거나 로그오프하는 데 쓰일 뿐, 계정을 추가하거나 삭제하지는 못한다. 계정 관리는 [설정] → [계정]에서 한다.


17. 다음 중 인터넷을 수동으로 연결하기 위하여 지정해야 할 TCP/IP 구성 요소로 옳지 않은 것은?
24상시, 20.2, 12.2, 10.3, 09.3

① IP 주소
② 서브넷 마스크
③ 어댑터 주소
④ DNS 서버 주소

정답: ③
해설: TCP/IP를 수동으로 설정할 때는 해당 컴퓨터를 식별하는 IP 주소, 네트워크 영역을 구분하는 서브넷 마스크, 다른 네트워크로 나가는 기본 게이트웨이, 도메인 이름을 IP 주소로 변환하는 DNS 서버 주소 등을 입력한다. 어댑터 주소는 네트워크 어댑터에 부여된 물리적 주소(MAC 주소)를 뜻하며 일반적인 수동 TCP/IP 구성 항목이 아니므로 ③이 정답이다.


18. 다음 중 인터넷 서비스에서 PING(Packet InterNet Groper)의 기능에 관한 설명으로 옳은 것은?
22상시, 18.2, 14.1, 09.1, 07.4, 01.3

① 인터넷 상에서 쪽지를 알 수 있도록 하는 기능이다.
② 인터넷 속도가 느릴 경우에는 어느 구간에서 정체가 있는가를 알기 위하여 인터넷 서버까지의 경로를 추적하는 기능이다.
③ 원격 컴퓨터가 현재 인터넷에 연결되어 정상적으로 네트워크가 작동하고 있는지 파악할 수 있는 서비스이다.
④ 여러 지역에 분산되어 있는 데이터베이스로부터 정보를 검색할 수 있게 하는 서비스이다.

정답: ③
해설: PING은 ICMP 에코 요청을 대상 컴퓨터에 보내 응답 여부와 왕복 시간을 확인하는 명령이다. 이를 통해 대상이 네트워크에서 응답하는지와 통신 상태를 간단히 점검할 수 있으므로 ③이 옳다. 서버까지 거치는 경로와 구간별 응답을 추적하는 ②의 기능은 TRACERT에 해당한다. ①의 쪽지 기능이나 ④의 분산 데이터베이스 검색 기능과는 관계없다. 다만 방화벽이 ICMP 응답을 차단하면 컴퓨터가 작동 중이어도 PING 응답이 없을 수 있다.


19. 다음 중 한글 Windows 10에서 ‘명령 프롬프트’ 창을 표시하기 위해 ‘실행’ 창에 입력해야 하는 것은?
22상시, 21상시

① cmd
② command
③ ping
④ tracert

정답: ①
해설: Windows 10에서 `Windows 키 + R`로 [실행] 창을 연 뒤 `cmd`를 입력하면 명령 프롬프트가 실행된다. `ping`과 `tracert`는 명령 프롬프트 안에서 사용하는 네트워크 진단 명령이다. `command`는 과거 DOS 계열에서 사용하던 명령 해석기 이름으로, Windows 10의 표준 명령 프롬프트 실행 명령은 `cmd`이다.
