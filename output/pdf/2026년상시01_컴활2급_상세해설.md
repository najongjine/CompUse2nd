## 제1과목 컴퓨터 일반

### 1. 프로그래밍 언어 - 정답 ③ Python

지문의 핵심 단서는 **인터프리터 방식**, **다양한 라이브러리**, **스크립트 언어**, **간결하고 읽기 쉬운 문법**, **자동화 작업에 널리 사용**입니다. 이 특징을 모두 만족하는 언어가 Python입니다.

- Python은 소스 코드를 한 줄씩 해석·실행하는 인터프리터 언어로 분류합니다. 실제 구현에서는 바이트코드 등의 중간 단계를 거치지만 시험에서는 인터프리터 방식으로 기억합니다.
- Perl도 스크립트 언어이지만, 빅데이터·자동화와 쉬운 문법이라는 출제 문맥에서는 Python이 정답입니다.
- Java와 C#은 보통 컴파일 과정을 거쳐 실행되는 대표적 객체지향 언어로 분류합니다.

**암기 포인트:** Python = 인터프리터, 객체지향, 풍부한 라이브러리, 데이터 분석·AI·자동화.

### 2. Windows 10 작업 표시줄 - 정답 ①

①의 **아이콘 보기 형식이나 정렬 방식**은 작업 표시줄 설정 항목이 아니라 바탕 화면의 바로 가기 메뉴에서 설정하는 내용입니다.

- 작업 표시줄은 데스크톱 모드에서 자동 숨기기를 설정할 수 있습니다.
- 위치는 화면의 위·아래·왼쪽·오른쪽으로 바꿀 수 있습니다.
- 작업 표시줄이 꽉 찼을 때 같은 앱의 단추를 하나로 묶어 표시할 수 있습니다.

**구분:** 바탕 화면의 아이콘 크기·정렬은 바탕 화면 메뉴, 앱 단추 묶기·자동 숨기기·위치는 작업 표시줄 설정입니다.

### 3. 정보 보안 조치 - 정답 ④

DNS는 사람이 읽는 도메인 이름을 IP 주소로 변환하는 이름 해석 서비스입니다. DNS 설정을 임의로 바꾸는 것은 불법 접근 방지 대책이 아니며, 오히려 접속 장애나 악성 사이트 유도 같은 위험을 만들 수 있습니다.

- 방화벽은 허용·차단 규칙에 따라 네트워크 트래픽을 통제합니다.
- 중요한 데이터의 암호화는 유출 시 평문 노출을 막습니다.
- 접근 통제 도구는 인증과 권한에 따라 자원 사용을 제한합니다.

**시험 함정:** DNS는 주소 변환, 방화벽은 통신 통제, 암호화는 기밀성 보호입니다.

### 4. 작업 표시줄 바로 가기 메뉴 - 정답 ④

작업 표시줄의 빈 곳을 마우스 오른쪽 단추로 누르면 피플, 터치 키보드, 작업 보기 단추의 표시 여부 등을 선택할 수 있습니다. **개인 설정 표시**라는 항목은 없습니다. 개인 설정은 바탕 화면의 바로 가기 메뉴나 Windows 설정에서 엽니다.

### 5. 악성코드 - 정답 ②

②는 웜(Worm)을 잘못 설명했습니다. 웜은 다른 프로그램 파일에 자신의 명령어를 붙여 기생하는 방식이 아니라, **스스로 복제하며 네트워크 등을 통해 확산**하는 독립형 악성코드입니다.

- 파일 감염 바이러스는 실행 파일 등에 붙어 감염되며 실행을 계기로 전파됩니다.
- 트로이 목마는 정상 프로그램처럼 위장해 사용자의 실행을 유도합니다.
- 매크로 바이러스는 문서의 매크로 기능을 악용해 문서 파일을 중심으로 감염됩니다.

**비교:** 바이러스 = 숙주 필요, 웜 = 자기 복제·독립 확산, 트로이 목마 = 정상 프로그램으로 위장.

### 6. 웹 브라우저 기능 - 정답 ④

웹 브라우저는 웹 페이지 열람, 저장·인쇄, HTML/PDF 확인, 자주 방문한 사이트 기록과 즐겨찾기 등을 제공합니다. 하지만 방문한 웹 사이트의 서버 내용을 **편집**하는 권한이나 기능은 일반 브라우저에 없습니다. 개발자 도구로 화면의 DOM을 임시 변경해도 서버 원본이 수정되는 것은 아닙니다.

### 7. 사물 인터넷(IoT) - 정답 ④

IoT 기기가 네트워크를 사용하면 통신 비용이 생길 수 있고, 다양한 소형 기기와 무선 환경 때문에 보안 적용과 지속적 업데이트가 쉽지 않습니다. 따라서 **통신 비용이 절감되고 보안 적용이 용이해진다**는 ④가 옳지 않습니다.

- 디바이스·센서는 데이터를 수집하고, 클라우드와 AI는 저장·분석에 활용됩니다.
- IoT는 사물·사람·공간을 연결해 정보를 수집하고 상호작용하는 융복합 기술입니다.
- 단순 연결을 넘어 분석 결과로 자동 판단·제어하는 방향으로 발전합니다.

### 8. Windows 메모장 - 정답 ②

메모장은 기본적인 **일반 텍스트 편집기**이므로 그림·차트와 같은 OLE 개체를 문서 안에 삽입할 수 없습니다.

- 기본 저장 확장자는 `.txt`입니다.
- 현재 날짜/시간 삽입 기능과 찾기 기능을 제공합니다.
- OLE 개체를 포함하는 서식 문서는 워드패드나 워드프로세서 계열과 구분해야 합니다.

### 9. 연산 속도 단위 - 정답 ④ 1ps

단위는 값이 작을수록 더 짧은 시간이므로 더 빠릅니다.

`1ms = 10^-3초`, `1μs = 10^-6초`, `1ns = 10^-9초`, `1ps = 10^-12초`입니다. 따라서 피코초(ps)가 가장 빠릅니다.

**순서:** ms > μs > ns > ps (시간의 길이), 속도는 그 반대 방향으로 빠릅니다.

### 10. SATA - 정답 ①

SATA는 **Serial ATA**, 즉 직렬 전송 방식의 저장장치 인터페이스입니다.

- 핫 플러그인을 지원할 수 있습니다.
- PATA처럼 하나의 케이블에 Master/Slave를 정하는 방식이 아닙니다. 장치가 포트와 일대일로 연결됩니다.
- 병렬 ATA보다 케이블이 가늘고 데이터 전송 속도가 빠릅니다.

### 11. IPv6 - 정답 ②

IPv6 주소의 각 부분은 세미콜론이 아니라 **콜론(:)**으로 구분합니다.

- 총 128비트입니다.
- 16진수로 표현합니다.
- 일반적으로 16비트씩 8개 그룹으로 나눕니다.
- 연속된 0 그룹은 `::`로 한 번 축약할 수 있습니다.

### 12. Windows 프린터 설치 - 정답 ②

표준 사용자 계정이라고 해서 네트워크 프린터를 전혀 설치하지 못하고 로컬 프린터만 설치할 수 있는 것은 아닙니다. 네트워크 검색과 정책·드라이버 권한이 허용된다면 네트워크 프린터도 연결할 수 있습니다.

- 설치할 프린터 유형은 로컬, Bluetooth, 무선, 네트워크 검색 프린터 등에서 선택할 수 있습니다.
- 여러 프린터 중 기본 프린터를 정할 수 있습니다.
- 설정의 프린터 및 스캐너 메뉴에서 장치를 추가합니다.

### 13. 디지털·아날로그 컴퓨터 - 정답 ③

③이 올바른 비교입니다. 아날로그 컴퓨터는 미분·적분 등 연속량 계산에 적합하고, 디지털 컴퓨터는 산술·논리 연산을 중심으로 이산 데이터를 처리합니다.

- ①은 처리 대상을 서로 뒤바꿨습니다. 디지털은 숫자·문자 같은 이산 데이터, 아날로그는 전류·전압·온도 같은 연속량을 처리합니다.
- ②는 회로를 뒤바꿨습니다. 디지털은 논리 회로, 아날로그는 증폭 회로 중심입니다.
- ④도 용도를 뒤바꿨습니다. 아날로그는 특수 목적, 디지털은 범용으로 널리 사용됩니다.

### 14. 통신 선로의 중계 장치 - 정답 ③ Repeater

리피터는 전송 중 약해지거나 왜곡된 디지털 신호를 **재생·증폭**해 더 먼 거리로 전달합니다.

- 게이트웨이: 서로 다른 프로토콜이나 네트워크를 연결합니다.
- 모뎀: 디지털과 아날로그 신호를 상호 변환합니다.
- 라우터: IP 주소를 바탕으로 패킷의 최적 경로를 선택합니다.

### 15. Windows 접근성 - 정답 ①

두 대 이상의 모니터로 화면을 확장하는 **다중 디스플레이**는 시스템의 디스플레이 설정에서 다루며 접근성 기능이 아닙니다.

- 돋보기는 화면을 확대합니다.
- 내레이터는 화면의 텍스트와 요소를 음성으로 읽습니다.
- 화상 키보드는 실제 키보드 없이 화면에서 입력하게 합니다.

### 16. 컴퓨터 범죄 - 정답 ④

인터넷 쇼핑몰 상품 가격 비교표 작성은 정상적인 정보 활용 행위로, 컴퓨터 범죄가 아닙니다. 전자문서 불법 복사, 전산망을 통한 개인정보 유출, 중요 정보 위조·변조는 정보통신 기술을 악용한 범죄에 해당합니다.

### 17. 하드디스크 파티션 - 정답 ③

한 물리 디스크를 여러 파티션으로 나누면 각 파티션을 별도 볼륨처럼 관리할 수 있으며, **파티션별로 서로 다른 운영체제나 파일 시스템을 사용할 수도 있습니다.** 따라서 모든 파티션에 동일한 운영체제만 설치할 수 있다는 ③이 틀렸습니다.

- 새 파티션은 사용 전에 파일 시스템으로 포맷해야 합니다.
- 하나의 파티션에는 일반적으로 한 종류의 파일 시스템을 적용합니다.

### 18. 유틸리티 프로그램 - 정답 ②

유틸리티는 운영체제의 기능을 보완해 파일 관리, 압축, 백업, 보안, 디스크 점검 같은 특정 작업을 편리하게 수행하는 소프트웨어입니다. **컴퓨터 동작에 반드시 필요한 필수 소프트웨어**라는 설명은 부적절합니다. 필수적인 자원 관리와 기본 운영은 운영체제의 역할입니다.

### 19. 바이트(Byte) - 정답 ③

1바이트는 데이터를 표현하는 기본 단위이지, 명령어를 처리하는 가장 기본 단위가 아닙니다. CPU가 한 번에 처리하기에 적합한 데이터 크기는 **워드(Word)**라고 합니다.

- 1Byte = 8bit입니다.
- 영문자·숫자는 보통 1바이트, 전통적 문자 코드에서 한글·한자는 2바이트로 설명합니다.
- 8비트로는 `2^8 = 256`가지 상태를 표현합니다.

### 20. 그래픽 기법 - 정답 ② Rendering

컴퓨터 프로그램으로 3차원 모델에 명암·색상·질감 등을 계산해 사실적인 2차원 영상을 만드는 과정은 **렌더링**입니다.

- 안티앨리어싱: 계단 현상을 주변 색과 섞어 부드럽게 보이게 합니다.
- 인터레이싱: 이미지의 대략적인 모습을 먼저 보이고 점차 자세히 표시합니다.
- 메조틴트: 수많은 점과 선을 이용해 명암을 표현합니다.

## 제2과목 스프레드시트 일반

### 21. 피벗 테이블 - 정답 ①

원본 데이터가 변경되었다고 피벗 테이블 결과가 즉시 자동 변경되는 것은 아닙니다. **피벗 테이블 분석 → 새로 고침**을 실행해야 원본 변경이 반영됩니다.

- 외부 데이터도 피벗 원본으로 사용할 수 있습니다.
- 계산 필드 등 사용자가 만든 수식을 추가할 수 있습니다.
- 대량 데이터를 행·열·값·필터로 재배치해 다양한 관점에서 요약합니다.

### 22. 수식 오류 메시지 - 정답 ④ #VALUE!

잘못된 인수나 피연산자, 또는 수식이 기대하는 자료형과 다른 값을 사용하면 `#VALUE!` 오류가 발생합니다.

- `#DIV/0!`: 0 또는 빈 셀로 나눔.
- `#NUM!`: 표현 범위를 벗어난 숫자 또는 잘못된 수치 계산.
- `#NAME?`: 함수명·정의된 이름·텍스트 표기 등을 인식하지 못함.
- `#VALUE!`: 자료형이나 인수·연산자가 부적절함.

### 23. 평균 초과 지점 수 - 정답 ②

올바른 수식은 `=COUNTIF(B2:B6, ">"&AVERAGE(B2:B6))`입니다.

1. `AVERAGE(B2:B6)`은 73.2입니다.
2. 조건 연산자 `">"`와 평균값을 `&`로 연결해 `">73.2"`라는 조건을 만듭니다.
3. 73.2보다 큰 값은 88, 75, 82로 3개입니다.

`COUNTIF` 구문은 `COUNTIF(조건범위, 조건)`입니다. 함수 계산값을 비교 조건에 넣을 때 연산자를 따옴표로 묶고 `&`로 연결하는 형식을 기억해야 합니다.

### 24. 차트 - 정답 ①

꺾은선형 차트는 하나의 계열만 갖는 차트가 아니며 여러 데이터 계열을 동시에 나타낼 수 있습니다. 또한 기본적으로 2차원뿐 아니라 3차원 꺾은선형 차트도 제공됩니다.

- 방사형: 중심에서 뻗은 축을 따라 여러 항목의 값을 비교합니다.
- 분산형: 두 수치 변수의 관계를 XY 좌표로 나타냅니다.
- 원형: 전체에 대한 각 항목의 비율·기여도를 한 계열로 표현합니다.

### 25. 이름 정의 - 정답 ④

정의된 이름은 수식에서 참조할 때 기본적으로 **절대 참조**로 동작합니다.

- 첫 글자는 숫자로 시작할 수 없고 문자, 밑줄, 역슬래시 등으로 시작해야 합니다.
- 같은 통합 문서 범위에서는 동일한 이름을 중복 정의할 수 없습니다. 단, 시트 범위 이름은 범위가 다르면 구별될 수 있습니다.
- 영문 대·소문자를 구분하지 않습니다.

### 26. 부분합 추가 - 정답 ②

기존 부분합을 유지하면서 새 부분합을 추가하려면 부분합 대화상자에서 **'새로운 값으로 대치'를 해제**해야 합니다. 이 옵션이 선택되어 있으면 기존 부분합이 새 설정으로 바뀝니다.

- '그룹 사이에 페이지 나누기'는 인쇄 페이지를 나누는 옵션입니다.
- '데이터 아래에 요약 표시'는 요약 행의 위치를 정합니다.

### 27. 채우기 핸들 - 정답 ①

문자와 숫자가 섞인 값은 Ctrl을 누른 채 채우기 핸들을 끌면 같은 내용을 복사할 수 있습니다. 따라서 ①이 옳습니다.

- 연속한 두 숫자를 입력하고 두 셀을 선택해 끌면 두 값의 차이를 간격으로 하는 수열이 만들어집니다. 두 번째 값만 반복되지 않습니다.
- 숫자 하나를 Ctrl과 함께 끌면 일반 복사가 아니라 연속 데이터가 만들어지는 동작과 구분해야 합니다.
- 사용자 지정 목록은 첫 항목을 입력한 뒤 보통 Ctrl 없이 채우기 핸들을 끌어 목록을 확장합니다.

### 28. 자동 필터 - 정답 ④

자동 필터는 여러 필드에 조건을 지정할 수 있습니다. 각 열에 지정한 조건은 보통 **AND 조건**으로 함께 적용됩니다. 따라서 여러 필드를 대상으로 조건을 지정할 수 없다는 ④가 틀렸습니다.

- 목록 단추로 조건에 맞는 행만 표시합니다.
- 조건 불일치 데이터는 삭제되지 않고 잠시 숨겨집니다.
- 필터 결과 행만 별도 위치로 복사할 수도 있습니다.

### 29. 워크시트 작업·관리 - 정답 ②

열 머리글의 오른쪽 경계선을 더블클릭하면 기본 너비로 돌아가는 것이 아니라, 그 열에서 가장 긴 표시 내용에 맞추는 **열 너비 자동 맞춤**이 실행됩니다.

- 시트 삭제는 일반적으로 실행 취소할 수 없습니다.
- 그룹화된 시트에서는 여러 시트에 같은 입력·편집을 동시에 적용할 수 있습니다.
- 연속된 시트 탭 선택에는 Shift를 사용합니다. 떨어진 시트는 Ctrl을 사용합니다.

### 30. 매크로 대화상자 - 정답 ①

매크로 대화상자에서 바로 가기 키나 설명을 바꾸는 단추는 **옵션**, 매크로의 이름이나 명령 코드를 고치는 단추는 **편집**입니다. 따라서 ㉠ 옵션, ㉡ 편집인 ①이 맞습니다.

### 31. 페이지 나누기 - 정답 ③

행 높이·열 너비 변경은 자동 페이지 나누기 위치에 영향을 줍니다. 수동 페이지 나누기는 사용자가 지정한 위치를 유지하므로 ③의 설명은 반대로 되어 있습니다.

- 자동 페이지 나누기는 용지 크기, 여백, 배율, 행·열 크기에 따라 Excel이 계산합니다.
- 수동 페이지 나누기는 사용자가 삽입한 위치입니다.
- 미리 보기에서 파선은 자동, 실선은 수동 페이지 나누기를 나타냅니다.

### 32. 찾기 및 바꾸기 - 정답 ②

서식을 지정하면 특정 서식이 적용된 셀도 검색할 수 있습니다. 따라서 숫자 셀만 찾을 수 있다는 ②가 틀렸습니다. 텍스트와 숫자 모두 값·수식·서식 조건에 따라 찾을 수 있습니다.

- `*`는 임의의 여러 문자, `?`는 임의의 한 문자를 뜻하는 와일드카드입니다.
- 검색 범위는 현재 시트 또는 통합 문서 전체로 정할 수 있습니다.
- 모두 찾기는 일치 항목을 목록으로 보여 줍니다.

### 33. Delete 키 - 정답 ②

셀에서 Delete를 누르면 **내용만 지워지고 서식은 유지**됩니다. 따라서 내용과 서식이 함께 지워진다는 ②가 틀렸습니다.

- 메모/노트는 내용 지우기와 별개이므로 그대로 남을 수 있습니다.
- 홈 → 지우기 → 내용 지우기, 바로 가기 메뉴의 내용 지우기 역시 내용 삭제에 해당합니다.
- 서식까지 없애려면 '모두 지우기' 또는 '서식 지우기'를 사용해야 합니다.

### 34. 한자·특수문자 입력 - 정답 ④

한글 **모음만** 입력한 뒤 한자 키를 누르면 특수문자 목록이 나타납니다. 아무 글자나 표시되지 않는 것이 아닙니다. 따라서 ④가 틀렸습니다.

- 입력한 한글 단어를 선택하거나 커서를 둔 뒤 한자 키를 눌러 한자로 변환합니다.
- 두 글자 이상은 단어 단위로 입력한 뒤 변환 후보를 고를 수 있습니다.
- 한글 자음을 입력하고 한자 키를 누르면 자음별 특수문자 목록이 나타납니다.

### 35. 고급 필터 - 정답 ② (3개)

조건 범위 A9:B11은 첫 행이 필드명이고, 아래 두 행이 조건입니다. 같은 행의 조건은 AND, 서로 다른 행의 조건은 OR로 연결됩니다.

- 조건 범위에는 같은 필드명인 `합계`가 두 번 쓰였습니다. 10행은 `합계 < 96 AND 합계 > 90`이므로 합계 92인 김진아와 94인 장영주가 해당합니다.
- 11행은 `합계 < 70`이므로 합계 65인 김시내가 해당합니다.
- 최종 결과는 김진아, 장영주, 김시내의 3개 레코드입니다.

**핵심 규칙:** 고급 필터에서 한 행 = AND, 다른 행 = OR. 조건 필드명은 원본 필드명과 정확히 같아야 합니다.

### 36. 페이지 설정의 시트 탭 - 정답 ④

용지 여백은 **여백 탭**, 용지 크기는 **페이지 탭**에서 설정합니다. 둘 다 시트 탭의 기능이 아니므로 ④가 틀렸습니다.

시트 탭에서는 인쇄 영역, 인쇄 제목, 눈금선, 행·열 머리글, 메모/노트 인쇄 방식, 페이지 순서 등을 설정합니다.

### 37. 선택 영역에서의 입력 - 정답 ①

B2:C6이 선택된 상태에서 B2에 입력하고 Shift+Enter를 누르면 일반적인 이동 방향의 반대인 위쪽으로 이동하되, 선택 영역 안에서 순환하여 **B3이 아니라 C6 쪽으로 이동**합니다. 따라서 B3으로 이동한다는 ①이 틀렸습니다.

- Enter는 기본적으로 아래쪽 다음 셀로 이동합니다.
- Ctrl+Enter는 선택 영역 전체에 같은 데이터를 한 번에 입력합니다.
- Alt+Enter는 한 셀 안에서 줄을 바꿉니다.

### 38. 텍스트로 인식되지 않는 입력 - 정답 ②

`0 1/4`처럼 정수 0과 공백 뒤에 분수를 입력하면 Excel은 이를 숫자 **1/4**로 인식합니다. 따라서 텍스트로 인식되지 않는 것은 ②입니다.

- `01:02AM`은 문제 표기처럼 유효하지 않거나 환경에 따라 텍스트로 취급될 수 있습니다.
- 앞에 작은따옴표를 붙인 `'1234`는 강제로 텍스트가 됩니다.
- `1월30일`도 문맥과 지역 설정에 따라 날짜로 인식될 수 있으므로 실제 시험에서는 작은따옴표의 강제 텍스트 규칙과 분수 입력 형식을 정확히 구분합니다.

### 39. 틀 고정 및 창 나누기 - 정답 ③

창 나누기 구분선은 보기 → 창 → **나누기를 다시 선택**하거나, 분할선을 창 가장자리로 끌거나 더블클릭해 제거할 수 있습니다. '숨기기'를 선택한다는 ③이 틀렸습니다.

- 창 나누기는 셀 포인터 위치를 기준으로 수직·수평·양방향 분할이 가능합니다.
- 창 나누기 자체는 인쇄 결과에 영향을 주지 않습니다.
- 첫 행 고정은 현재 셀 위치와 관계없이 보기 → 틀 고정 → 첫 행 고정으로 실행합니다.

### 40. 매크로 - 정답 ①

같은 통합 문서에 **같은 이름의 매크로를 중복 작성할 수 없습니다.** 매크로 이름은 해당 범위에서 고유해야 하므로 ①이 틀렸습니다.

- 바로 가기 키에 영문 대문자를 지정하면 실제 실행 조합에 Shift가 포함됩니다.
- 매크로 기록 시 '이 통합 문서'를 선택하면 해당 문서에 저장되고 그 문서에서 사용할 수 있습니다.
- 매크로 보안 설정으로 실행 허용 수준을 관리할 수 있습니다.

## 마지막 정리 - 자주 나오는 구분

- **웜 / 바이러스 / 트로이 목마:** 자기 복제 / 숙주 파일 감염 / 정상 프로그램 위장
- **게이트웨이 / 리피터 / 라우터 / 모뎀:** 망·프로토콜 연결 / 신호 재생 / 경로 선택 / 신호 변환
- **바이트 / 워드:** 문자 표현의 기본 단위 / CPU가 처리하기 적합한 단위
- **자동 필터 / 고급 필터:** 목록 단추로 간단 필터 / 별도 조건 범위와 AND·OR 조합
- **Delete / 모두 지우기:** 내용만 삭제 / 내용·서식 등 전체 삭제
- **Enter / Shift+Enter / Ctrl+Enter / Alt+Enter:** 아래 이동 / 반대 이동 / 선택 영역 동시 입력 / 셀 내부 줄바꿈
